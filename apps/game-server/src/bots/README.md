# 중간 난이도 연습 봇

`chooseBotCommand(gameKey, gameView, randomInt)`는 서버가 해당 자리의 `projectGame`으로 만든 개인 View만 받는다. 반환값은 게임 명령 하나 또는 `null`이다. 전체 상태, 상대 손패, 비공개 역할, 덱 순서, DB, 네트워크, 시계에 접근하지 않는다. 난수 함수가 같으면 같은 View에서 같은 선택을 한다.

- 별길 탐험: 길의 예상 수익과 카드 순서, 지원 배수, 상대에게 도움이 되는 버림을 비교한다.
- 빛의 공방: 할인·후원자·점수에 기여하는 작품을 목표로 자원을 모으며, 초과 토큰은 목표에 덜 필요한 색부터 반환한다.
- 밤의 의회: 도시 색과 자금에 맞춰 역할을 고르고, 자원·능력·건설·철거를 선택한다. 공개되지 않은 다른 사람의 역할을 알지 못한다.
- 황혼의 신호: 무료 방패, 대응, 치명상 회복을 사용한다. 자기 진영과 공개된 대장을 기준으로 대상을 추정하며 모르는 진영은 모르는 상태로 판단한다.
- 넘버가든: 랙의 합법적 묶음과 보드 끝 확장, 조커 교체·재사용을 탐색한다. 후보600개·빔20개·깊이12·확장60,000회로 상한을 둔다.

일부 비슷한 후보 중 무작위로 고른다. 완전 탐색이나 최적 플레이, 승률 등급을 보장하는 봇은 아니다. 다른 사용자에게 실제 친구인 것처럼 보이지 않도록 서버의 봇 표식을 유지한다.

반응 지연, 인간 연결 이탈 시 정지, 액터 확인, 버전·중복 명령 검사, 직렬 처리와 저장은 TableService가 담당한다. 정책은 명령을 코어에 반복 대입해 성공하는 것을 찾지 않는다.

`test/bot-policies.test.ts`는 다섯 게임의 실제 순수 엔진에 정책 명령을 적용해65판의 합법 진행과 자연 종료를 검사한다. 입력 불변성, 같은 View의 결정성, 숨겨진 덱 순서 독립성, 종료·일시정지 시 무행동도 확인한다. `test/garden-bot.test.ts`는 최초등록·조커·재배열 경계를 추가로 검사한다.
