# Paper Club 색감·마감 변경 기록

작업일: 2026-10-26. 첫 Paper Club 재디자인 이후 사용자는 전반적인 구성을 긍정하면서 푸른 색감이 마음에 들지 않으며 더 세련된 표현을 원한다고 요청했다. Hallmark, Impeccable, UI UX Pro Max를 함께 적용하는 후속 작업이다.

## 범위와 방향

이번 범위는 **restyle**이다. 기존 로비·대기실·다섯 게임·결과·대화상자·갤러리의 구성, 카드 그림, 게임 문구, 링크·필드·이벤트 연결을 유지한다. 새 페이지나 기능을 만들거나 조작 순서를 재구성하지 않는다.

방향은 **Paper Club, Ink and Vermilion**이다. 푸른 공통 바탕과 파란 행동색을 걷어내고, 중립 종이색과 차콜로 읽기·조작의 위계를 만든다. 두 고리 브랜드와 포커스에는 녹슨 주홍을 제한적으로 사용한다. 게임 아트의 원래 색이 화면의 가장 풍부한 색으로 남게 한다.

이 방향은 이전에 사용자가 거부한 누런 회색·베이지 `#F4F1EA`·`#E7E3D9`로 돌아가는 변경이 아니다. 레퍼런스의 아이보리는 UI가 그림을 받치는 방식의 근거로만 사용하고, 실제 앱 표면은 더 중립적인 `#f8f8f6`·`#fffffe`로 정했다. 현재 기준은 [DESIGN.md](../DESIGN.md), 이전 구성 변경은 [첫 Paper Club 기록](paper-club-redesign.md)에 남긴다.

## 적용한 색과 표면

실제 값의 기준은 `apps/web/app/tokens.css`다. 모든 색은 루트 토큰을 통해 적용한다.

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 전체 바탕 | `--color-canvas` | `#f8f8f6` |
| 카드·입력·대화상자 | `--color-paper` | `#fffffe` |
| 보조 표면 / 더 짙은 표면 | `--color-paper-2` / `--color-paper-3` | `#efefeb` / `#e4e4de` |
| 본문 / 보조 글자 | `--color-ink` / `--color-muted` | `#292b28` / `#63685f` |
| 구분선 / 강한 경계 | `--color-rule` / `--color-border-strong` | `#dcdfd7` / `#858d80` |
| 주 행동 / 호버 | `--color-accent` / `--color-accent-hover` | `#343c35` / `#222a24` |
| 선택 배경 | `--color-accent-soft` | `#e6ebe2` |
| 브랜드·포커스 / 옅은 브랜드 배경 | `--color-brand` / `--color-brand-soft` | `#a24d37` / `#f3e6df` |
| 카드 경계 | `--color-card-edge` | `#cbd0c4` |

주 행동은 차콜의 채워진 버튼, 키보드 포커스는 녹슨 주홍의 윤곽선으로 구별한다. 선택·현재 차례·준비·오류는 기존 문장·아이콘·형태와 함께 표현한다. 수트, 자원, 게임별 표지의 고유 색은 규칙과 아트의 의미를 가지므로 일괄 탈색하지 않는다. `mint`, `gold`, `star-blue`, `--board-blue`처럼 과거 색을 담은 이름은 호환용 식별자로 유지하지만 값은 새 공통 체계를 참조한다.

공통 제목 굵기는 주로 700으로 낮춰 카드 그림과 읽기 정보가 경쟁하지 않게 한다. 자체 호스팅 Pretendard, 제목 크기·줄바꿈·반응형 기준은 유지한다. 게임 카드의 숫자·지원 배수·이름 표찰의 크기와 굵기는 바꾸지 않는다. 홈 샘플 카드의 단단한 검정 오프셋 그림자는 `0 6px 14px #292b2826`의 부드러운 그림자로 바꾼다. 공개 카드와 드래그 카드의 그림자도 공통 잉크를 기준으로 하되 기존 상태 차이를 유지한다.

## 공식 레퍼런스에서 확인한 것

## 세 스킬의 역할

- **Hallmark:** 기존 구성을 지키는 restyle 범위, 루트 색·서체 토큰, 입력·링크·이벤트 보존, 렌더 점검과 독립 마감 검토를 적용한다. 새 랜딩 페이지 구조나 다른 게임의 구성으로 교체하지 않는다.
- **Impeccable:** 게임을 고르고 조작하는 화면의 읽기 위계·표면·상태 대비를 우선한다. 큰 장식과 강조색을 줄이고 제목 무게와 실제 카드의 깊이를 정돈한다.
- **UI UX Pro Max:** 자동 gaming design-system 결과는 3D 표현과 네이비 계열이 중심이어서 현재 사용자 요청과 충돌하므로 채택하지 않았다. 명시적으로 조회한 minimalism 스타일의 절제 원칙은 참고하되 프로젝트 전체를 데이터셋의 추천 테마·서체·구조로 교체하지 않는다. 색 대비·의미 있는 상태·포커스·터치 표적·모션 감소 기준은 최종 점검에 사용한다.

## 보존하는 계약

- 링구링구와 다섯 자체 게임 이름, 내부 `star-trails` 식별자, 두 고리 로고의 형태.
- 확정 동물 50면과 다른 자체 게임 아트, 상단 숫자·가운데 그림·하단 이름의 카드 구조.
- 카드·공개 스택·버림 더미의 치수와 겹침, 서버 View 순서, 지원 배수와 게임 규칙.
- 별길의 데스크톱 오른쪽 개인 영역, 공방 작업대, 모바일 손패 넘김과 기존 반응형 구성.
- 기존 라우트·문구·버튼명·입력·핸들러·초대·준비·재접속·재경기·드래그·키보드 대안.
- 인증된 행동 주체, 순수 규칙 함수, 명령 직렬 처리와 저장 후 승인, 비공개 정보의 서버 보관.

서버·게임 규칙·의존성·외부 인증·DB·운영 배포는 이번 변경 범위가 아니다. 앞선 실행에서 남은 `.impeccable/design.json`의 오래된 기록은 별도 문서 정합성 문제이며 이번 시각 작업의 부수 변경으로 수정하지 않는다.

## 검증

이번 변경에 대해 실제 실행했다. 로그는 `.scratch/ink-club-restyle/`에 보관한다.

- `npm run typecheck`: 전체 워크스페이스 통과.
- `npm run build`: 서버와 Next 프로덕션 빌드 통과, 정적 페이지 9개 생성.
- 기존 Playwright 6개 파일, **17개 테스트 통과**: 두 브라우저 자연 종료·새로고침/재접속·재경기, 네 추가 게임, 봇, 동물 50면과 추가 카드 그림, 360/390px 가로 넘침, 대화상자 키보드 포커스, 오류 복구. 변경 범위가 CSS뿐이므로 서버 규칙 단위 테스트를 중복 실행하지 않았다.
- Hallmark 28개 파일과 홈 5개 크기 렌더: **0 FAIL, 0 REFLEX**. 보존 기록은 링크 8/8, 필드 1/1, 핸들러 139/139, 제목 7/7이다. 기존 WARN 5개는 공방의 실제 자원 버튼 격자, 빈 테이블의 여러 줄 클릭 표면, 중립/텍스트/비활성 버튼의 F4 추정이며 렌더·소스로 판단했다.
- Impeccable 변경 CSS 9개 검사: 주 finding 0, advisory 276개. 199개는 기존 게임별 글자 크기, 77개는 기존 모서리 값이 문서의 간소화된 척도에 없다는 안내다. 사용자에게 유지하기로 한 게임 카드 치수를 자동 추천에 맞춰 바꾸지 않았다.
- 새 공통 팔레트 12조합 대비 검사 통과: 본문/바탕 13.43:1, 보조 글자/보조 표면 4.96:1, 버튼 11.38:1, 포커스/보조 표면 4.99:1, 입력 경계/종이 3.43:1. 전체 서비스의 접근성 적합성 인증을 뜻하지 않는다.
- 1280×800 프로덕션 홈을 스크립트 비활성으로 확인: 제목·실제 게임 5개·Pretendard·중성 바탕 표시, 가로 넘침과 깨진 이미지 없음. 게임 상호작용의 무스크립트 지원을 뜻하지 않는다.
- 독립 마감 검토: 전후 홈과 게임/대기실 12개 화면에서 비활성 시작 버튼이 활성처럼 보이는 문제 1건 발견. 공통 disabled 선택자의 우선순위를 높였다. 수정 후 기존 테이블/대화상자/복구 테스트 5개와 최종 빌드 통과. 새 데스크톱·모바일 캡처를 같은 검토자에게 전달해 **1건 resolved, ship** 판정을 받았다. 이는 발견된 수정 항목의 재검토 결과다.

외부 인증·PostgreSQL·운영 배포의 실제 검증 여부는 로컬 화면·브라우저 결과와 구분해 기록한다.
