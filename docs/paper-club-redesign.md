# Paper Club 리디자인 기록

작업일: 2026-10-26. 범위는 링구링구 홈·로비·대기실·다섯 게임·결과·규칙·설정·카드 갤러리의 시각 체계와 조작 배치다. 사용자는 다른 웹 카드게임을 함께 검토하고 기존 디자인을 전면 교체하며 적합한 테마를 적용해도 된다고 요청했다.

## 방향과 기존 결정의 관계

새 방향은 **Paper Club**이다. Hallmark의 Sticker 테마에서 카드의 명료한 윤곽과 작은 그림자, 표현력 있는 게임 색을 취하고, 실제 앱에는 흰 표면·밝은 청회색 바탕·짙은 한글·푸른 행동으로 적용한다. 한국어 Pretendard와 확정 동물 카드, 기존 자체 게임 그림을 사용한다. 테마 견본의 영문 서체·분홍 강조색·따뜻한 종이색을 그대로 옮기지 않는다.

2026-10-25에는 밝은 첫 게임을 홈과 다른 게임으로 확장하지 않는 제한이 있었다. 이번 사용자 요청은 전체 디자인 교체를 허용하므로 공통 밝은 셸을 전역에 적용하는 결정으로 갱신했다. 동물 아트 50면, 카드 숫자와 이름, 덱 60장, 게임명·규칙·공개 범위는 그 변경에 포함하지 않는다. 사용자가 거부한 누런 회색·베이지 `#F4F1EA`·`#E7E3D9`는 되살리지 않는다. 최종 시스템은 [DESIGN.md](../DESIGN.md)를 따른다.

## 공식 서비스에서 확인한 것

공개 페이지와 공식 문서를 2026-10-26에 확인했다. 로그인 후 실제 대전을 플레이한 비교는 아니다. 아래 적용 방향은 문서 관찰을 링구링구에 맞게 해석한 디자인 판단이다. 외부 서비스의 그림·로고·카드 문장·코드를 제품에 복사하지 않는다.

## 바꾼 문제와 화면 구성

- **홈과 게임 사이의 시각적 단절:** 어두운 네이비·라임 셸과 밝은 첫 게임을 공통 밝은 토큰으로 연결한다. `#f7f9fc` 바탕, 흰 표면, `#202c42` 글자, `#3159c9` 행동을 기준으로 삼는다.
- **홍보 장면의 크기:** 거대한 추상 포스터와 궤도 선 대신 확정된 멍이6·냥이10·수달8 카드 샘플을 보여 준다. 기존 짧은 제목과 만들기·초대 버튼을 유지하고 작은 다섯 게임 선반을 이어 붙인다. 모바일에서는 샘플 장면을 접어 게임 선택을 앞당긴다.
- **로비와 대기실의 밀도:** 내 테이블은 행 목록, 모바일 참가자는 짧은 행으로 정돈한다. 최대 정원의 빈자리와 봇 관리 기능을 삭제하지 않고 준비·시작 버튼까지의 거리를 줄인다. 모바일 탐색 메뉴는 두 번째 줄로 옮겨 기능을 유지한다.
- **공방의 먼 조작 영역:** 시장과 후원자는 왼쪽, 선택한 작품·빛 보관소·내 자원·예약·반환은 오른쪽 작업대로 묶는다. 좁은 화면은 한 열이며 새 작품 선택 시 행동 패널로 포커스와 최소 스크롤을 보낸다.
- **의회의 먼 능력·종료:** 손패와 역할·도시 능력·차례 종료를 한 작업 영역으로 묶는다. 모바일 손패와 공개 도시 카드는 각각 가로로 넘겨 보며 기존 선택과 건설 동작을 유지한다.
- **별길의 공개 스택과 먼 행동:** 1101px 이상에서 공개 보드를 왼쪽, 손패·행동·도움말을 오른쪽 400px 개인 영역으로 분리한다. 공개 보드의 상대→공용→내 길 순서와 전체 스택은 유지한다. 손패는 기존 88×148px 카드의 4열·4px 간격이며 행동 바가 바로 아래에 있다. 1100px 이하는 보드 아래 가로 손패와 행동, 도움말 숨김을 사용한다. 개인 영역 전체를 고정하는 동작은 뷰포트 높이 1200px 이상에서만 적용한다.
- **신호의 모바일 손패 넘김 단서:** 모바일 카드 폭을 132px로 정해 다음 카드 일부가 보이게 한다. 손패와 바로 아래 선택 효과·행동은 같은 영역에 유지한다.
- **카드보다 눈에 띄는 부가 장식:** 영문 대문자 상태 라벨·장식점·레이더 선을 덜어내고 의미 있는 SVG 아이콘과 보통 자간의 한국어를 사용한다. 신호 진영 공개는 높이 대신 opacity만 전환하고 OS 모션 감소를 따른다.
- **읽기와 선택 상태:** 주 행동과 선택·현재 차례를 푸른색으로 일관되게 표현하고 포커스를 즉시 표시한다. 공방 작품과 가든 타일에 선택 상태를 전달한다. 별길 숫자와 쌓임 구조는 보존하며 안내·점수의 읽기 크기를 정돈한다.

로컬의 이전 감사 기록 `docs/ui-ux-audit-2026-10-25.md`는 역사적 발견이다. 당시 별길의 카드가 숫자 요약으로 바뀌던 문제는 이후 실제 동물 카드 스택으로 바뀌었으므로 이번 현재 결함으로 다시 주장하지 않는다. 인증 복귀·게임 규칙 편집처럼 이번 시각 작업 밖의 문제를 해결했다고 주장하지 않는다.

## 보존한 동작과 자료

- 링구링구와 다섯 자체 게임 이름, 내부 `star-trails` 식별자, 기존 두 고리 브랜드.
- 확정 동물 50면과 지원 15장·숫자 45장의 60장 덱, 카드 상단 숫자/×2·가운데 그림·하단 동물 이름의 세 영역.
- 공개 길·버림 더미의 전체 스택, 실제 상단 숫자 노출, 서버가 준 순서, 상세 확인과 마지막 카드 가져오기의 구분.
- 게임별 rules/content 계약, 순수 판정 함수, 인증된 행동 주체, 직렬 명령·저장 후 승인, commandId·버전 처리.
- 서버에 남는 비공개 손패·덱과 플레이어별 View, 연결 복구·초대·준비·봇 관리·재경기·규칙·설정.
- 기존 라우트·핸들러·입력 필드·명령 payload·테스트용 버튼명. 테스트 통과를 위해 테스트를 변경하지 않는다.
- 기존 자체 아트와 폰트 라이선스. 개인 사진·`references/`·키·비밀 스냅샷을 공개 산출물에 추가하지 않는다.

기존 버튼명·접근가능 이름의 가운데점은 동작·테스트 hook 보존을 우선해 그대로 둔다. 카드 수트와 조커 별은 같은 의미의 SVG로 표시하며 기존 접근가능 이름을 유지한다. 두 경우를 일반 장식용 이모지·메타 문자열과 구별해 검토한다.

두 브라우저의 자연 종료·재접속, 외부 인증·DB·배포를 시각 캡처나 단일 브라우저 검사로 대체하지 않는다. 전체 WCAG 인증이나 모든 게임 예외의 검증을 이 문서에서 주장하지 않는다.

첫 `npm test` 실행과 단일 재확인에서 기존 봇 저장 재시도 테스트의 4초 시간 초과를 관찰했다. 소스 수정 없는 후속 단일 실행과 전체 재실행은 통과했으며 원인은 확정하지 않았다. 로컬의 `.scratch/paper-club-redesign/unit-flake.md`에 간헐적 실패 기록을 남겼다.

독립 Hallmark 마무리 검토는 `fix` 판정으로 두 항목을 지적했다. 별길의 멀리 떨어진 손패·행동은 오른쪽 개인 영역으로, 신호 모바일의 보이지 않던 다음 손패는 132px 카드 폭으로 해결했다. 부모 에이전트가 최종 E2E 재캡처를 확인하여 두 항목을 resolved로 기록했다. 공방은 최종 2열 캡처를 별도로 확인했다.

최종 linter의 WARN 5건은 직접 확인했다. 자원 은행의 3열은 실제 이름·재고·선택이 있는 게임 조작이며 홍보용 아이콘 목록이 아니다. 긴 새 테이블 버튼은 제목·설명이 있는 빈 상태 전체 표면이다. 홈의 초대는 텍스트 버튼이며, 테이블 행도 주 버튼이 아니다. 재경기 화면은 준비 여부에 따라 보조/주 버튼과 비활성 시작을 바꾸므로 동시에 활성인 주 행동이 경쟁하지 않는다. 공통 게임 패널 반복(F7)은 일관된 표면을 위한 의도로 답변했다.

## 재료

추가 사진이나 외부 이미지가 필요한 슬롯은 없다. 홈은 확정 동물 카드와 기존 자체 표지, 플레이는 기존 자체 카드·타일·역할 그림을 사용한다. 대표 그림을 교체한다면 확정 자산 매핑과 현재 숫자·이름의 HTML 배치를 먼저 확인한다.
