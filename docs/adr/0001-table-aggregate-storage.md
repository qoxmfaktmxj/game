# 테이블 단위의 원자적 저장

첫 구현은 한 게임 서버가 테이블·현재 세션·명령 처리 결과를 함께 저장한다. 부분 저장과 복구 경로를 줄이기 위해 정규화한 원본 SQL 초안 대신 PostgreSQL의 서버 전용 테이블에 하나의 테이블 문서를 JSONB로 저장하고, revision·ownerEpoch를 비교해 갱신한다. 원본 패키지 `contracts/001_initial.sql`과는 다른 구현 결정이며 새 migration만 적용한다.

이 선택은 운영 조회·집계의 편의와 문서 크기를 희생한다. 명령 기록과 결과가 무한히 누적되지 않도록 보관 정책이 필요하고, 다중 인스턴스 배포 전에 소유권 임대·경쟁 정책을 검증해야 한다. 개발용 JSON 어댑터는 동일 계약을 따르지만 단일 프로세스만 해당 디렉터리를 사용한다.
