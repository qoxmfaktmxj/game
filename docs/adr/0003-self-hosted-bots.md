# 자체 호스팅과 연습 봇

2026-10-24. 사용자는 혼자 테스트할 수 있는 중간 난이도 봇과 자체 리눅스 서버 배포를 요청했다. Vercel 준비를 기본 경로로 삼았던 이전 결정을 대체한다.

참가자의 `control`은 human 또는 bot이다. 예전 저장 문서의 누락값만 human으로 읽는다. 봇은 호스트가 대기·결과에서 추가하거나 제거하며, 자동 준비하고 사용자 로그인 경로로는 사칭할 수 없다. 게임 중에는 인간과 같은 명령 판정·버전 검사·직렬 저장 경로로 진행한다. 타이머는 서버에만 존재하고 재접속 시 저장된 상태에서 다시 예약한다.

정책 함수에는 해당 봇의 개인 View와 난수 함수만 전달한다. 상대 손패·비공개 역할·덱을 읽거나 임의의 게임 상태에 명령을 대입해 성공하는 것을 찾지 않는다. 상위 후보의 작은 무작위 변화와 제한된 탐색을 사용한다. ‘중간’은 설계 목표이며 사람 상대 승률 등급을 측정한 결과는 아니다.

호스팅은 Caddy, Next.js standalone, 단일 Colyseus 프로세스, PostgreSQL의 Docker Compose다. 약8GB RAM·100명 연결을 목표로 하며 실제 서버 수용량은 운영 환경의 부하 측정으로 확정한다. 여러 게임 서버 인스턴스의 테이블 소유권은 이번 범위가 아니다.

자체 서명 게스트 인증을 운영 모드로 별도 제공한다. 로컬 개발 인증의 loopback/비운영 제한은 유지한다. 키는 서버의 비밀 환경 파일에서 보존하며 DB 관리자와 런타임 역할은 분리한다. Supabase 어댑터는 선택 가능한 기존 코드로 남지만 이 배포에서 필수 서비스가 아니다.
