# 하늘 깡총 카드 확정 · 2026-10-26

사용자가 최종안을 확정하고 커밋·푸시를 요청했다. 멍이10은 회색·흰색 보더콜리 v5이며, 카드 앞면50종과 실제60장 덱 구성을 유지한다.

## 실제 화면 연결

- `PlayingCard`는 계열과 숫자/지원에 맞는 확정 그림을 사용한다. 손패·공개 길·버린 카드·확대 화면이 같은 컴포넌트를 사용한다.
- `/cards`에서50개의 서로 다른 그림과 품종/행동 이름을 표시한다. 대기실과 갤러리 대표 그림도 확정된 지원 카드 그림을 사용한다.
- 원본 전체가 보이도록 그림을 contain으로 맞추고 하단 표찰 공간을 분리한다.
- 내부 `star-trails` 식별자와 게임명 별길 탐험, 규칙·점수 산식은 유지한다.
- 홈의 브라우저 제목은 `링구링구`, 테이블 입장 후에는 `링구링구 - 게임이름`이다.

## 자산과 생성 근거

[최종 선택](sky-hop-final-selection.json), [정확 생성 프롬프트와 출처 식별자](sky-hop-approved-prompts.json)를 버전 관리한다. 이미지는 `apps/web/public/art/cards/sky-hop/`의 선택50개 PNG다. 개별1024×1536, 합계65,444,943 bytes,50개 고유 SHA-256이다.

실험 시안·미채택 이미지·원시 로컬 생성 기록은 삭제하지 않고 로컬에 보존한다. 저장소와 Docker 배포에는 최종 선택만 포함한다. 출처 기록의 `generated_images/<id>/<file>`은 생성 이력 식별자이며 서버에 필요한 파일 경로가 아니다. 개인 사진을 서비스 이미지로 사용하지 않았다.

선택을 추후 변경할 때 manifest를 갱신하고 `npx tsx scripts/sync-star-card-art.ts`로 작은 런타임 매핑을 만든다. `.gitignore`와 `.dockerignore`의 선택 파일 목록도 함께 갱신한다.

## 검증

- `npm run check`: 전 워크스페이스 타입 검사, 테스트166개 통과/실제PostgreSQL 필요 검사1개 건너뜀, 서버·웹 운영 빌드 통과. 원격의 게스트 재접속/부하 테스트 수정2개를 합친 상태에서 실행했다.
- `npm run test:art`: 확정50면 및 다른 게임231종 검사2개 통과. 파일·SHA-256·크기·런타임 경로와 회색 보더콜리 선택을 확인했다.
- 제목 E2E1개 통과: 홈→여러 게임 변경→새로고침→홈 복귀→뒤로가기. 최종 통합 후에도 실제 브라우저에서 홈 `링구링구`, 테이블 `링구링구 - 별길 탐험`을 확인했다.
- 실제 `/cards`의50개 그림 모두 로드,50개 고유 경로, 깨진 이미지0.360px 화면 가로 넘침 없음, 카드 숫자29px.
- 연습 봇과 실제 로컬 서버 게임에서 새 손패를 확인하고, 멍이 지원 카드를 드래그해 내 길1장/-40점/×2로 반영한 뒤 덱을 뽑아 손패8장 복귀를 확인했다. 카드 전신·하단 표찰·상대 위/내 카드 아래 배치를 시각 확인했다.
- 검토 중 발견한 터치 캡처 이전 취소와 드래그 직후 새 클릭 차단을 수정하고 기존 E2E에 회귀 시나리오를 추가했다. 이번 최종 검증에서 새 네이티브 터치 E2E와 실제 휴대전화 터치는 실행하지 않았다.
- `git diff --check` 통과. Docker ignore 선택 목록은 정적 검증했으며 이 컴퓨터에서 Docker 이미지 빌드는 실행하지 않았다.

이번 변경에는 DB migration이 없다. 원격 서버 배포는 사용자의 오픈클로에서 최신 main을 받은 뒤 기존 환경 파일·DB 볼륨을 유지하며 웹/게임 이미지를 재빌드해 진행한다. 실제 서버 배포 완료를 의미하지 않는다.
