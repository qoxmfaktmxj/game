# 나머지 네 게임의 카드 아트

2026-10-24 사용자 요청에 따라 별길 탐험과 같은 빛·재질·판타지 분위기의 독립 일러스트를 제작한다. 내장 `imagegen`을 그림마다 별도로 호출한다. 콜라주를 잘라 쓰거나 원작 사진을 사용하지 않는다.

| 게임 | 고유 그림 | 연결 기준 |
| --- | ---: | --- |
| 빛의 공방 | 100 | 작품 ID 90개, 후원자 ID 10개 |
| 밤의 의회 | 36 | 건물 종류 28개, 역할 순번 8개 |
| 황혼의 신호 | 42 | 카드 종류 22개, 인물 16개, 진영 4개 |
| 넘버가든 | 53 | 4색 × 숫자 1–13, 조커 1개 |

같은 종류의 물리 카드·타일 복사본에는 같은 그림을 쓴다. 황혼의 신호의 수트·랭크, 작품 비용·점수, 건물 효과, 타일 숫자는 그림과 분리된 기존 데이터 및 HTML로 표시한다. 조커가 숫자로 배치되어도 조커 그림을 유지한다. 공개 카드 종류 목록과 그림은 게임의 현재 비공개 손패나 진영을 알려주지 않는다. 진영 그림은 본인이 진영을 펼쳤을 때만 그린다.

## 파일과 재현 기록

- [전체 최종 프롬프트](remaining-card-prompts.json): 게임·키·표시명·최종 경로·프롬프트.
- [생성 원본 기록](generated-originals.jsonl): 각 호출의 원본 위치. 생성 진행에 따라 한 줄씩 저장한다.
- `apps/web/public/art/cards/{workshop,council,signal,garden}/`: 프로젝트에 복사한 최종 PNG.
- `scripts/prepare-card-art.ts`: 공개 콘텐츠 정의를 읽어 프롬프트 계획을 만든다. 이미지 API를 호출하지 않는다.
- `scripts/sync-card-art.ts`: 실제 저장된 그림만 공개 이미지 목록에 등록한다. 이미지 API를 호출하지 않는다.

게임 화면은 공통 `CardArt`와 Next.js Image 최적화를 사용한다. 원본 전체를 작은 카드에 직접 내려보내지 않는다. 게임별 큰 그림은 `/cards/workshop`, `/cards/council`, `/cards/signal`, `/cards/garden`에서 볼 수 있다. 게임의 **카드 그림** 링크는 새 탭으로 열려 진행 중인 테이블을 유지한다.

## 검증 상태

231종 제작과 적용 완료. 기존 별길 탐험 50종을 포함해 총 281종이다. 생성 원본 기록은 231개 고유 키·원본 경로를 포함한다.

- `npm run test:art`: 231종 누락 없음, 서로 다른 SHA-256, PNG 1024×1536 확인.
- 전체 TypeScript 검사 및 서버·웹 프로덕션 빌드 통과.
- 규칙 테스트 107개, 서버 테스트 59개 통과. 실제 PostgreSQL 테스트 1개는 환경 미설정으로 건너뜀.
- 빌드된 서버의 실제 SDK·복구 시험 4개 통과.
- Playwright 전체 16개 시나리오 통과(약 1.5분). 전체 그림 디코딩, 다섯 게임 화면, 초대·봇·재접속, 360px·390px 가로 넘침 검사를 포함한다.
- 실제 게임 스크린샷에서 숫자 가독성과 그림 배치를 확인했고 인물 초상화의 표시 위치를 조정했다. 산출물은 `artifacts/all-game-art-final/`에 보관한다.

운영 PostgreSQL·Docker·공개 도메인 배포는 이번 이미지 적용 검증에 포함하지 않는다.
