# 링구링구 디자인 방향

작성: 2026-10-23. 사용자 제공 설계 패키지와 디자인 참조를 바탕으로 첫 구현과 후속 디자인 개선에 적용한 방향이다. 플랫폼 이름은 **링구링구**, 첫 2인 카드게임 이름은 **별길 탐험**이다(2026-10-24 구분 반영). 게임 규칙은 `moyeotable_build_pack_v1/docs/05_game01_star_trails.md`를 따른다.

## 제품과 화면의 역할

친구끼리 초대 링크로 모여 같은 테이블에서 한 판을 끝내고 다시 시작하는 웹 보드게임 공간이다. 공개 홈은 참여하고 싶은 분위기를 만들고, 테이블과 게임 화면은 다음 행동을 분명하게 보여준다. 첫 게임만 플레이 가능하게 만들며 나머지 네 게임의 상세 규칙을 창작하지 않는다.

사용자가 완성도 있는 첫 구현 후 수정을 선호한다고 밝혔으므로 기존 자료에서 제품 맥락을 읽고 디자인 결정을 위임받아 진행한다. 색·서체·장식은 위임받은 디자인 판단이며, 링구링구라는 표시 이름은 사용자가 직접 지정했다.

## 선택한 시각 방향

따뜻한 종이와 짙은 초록 테이블을 대비한 작은 보드게임 카페. 홈페이지는 편집물처럼 여백과 타이포그래피의 크기 차이를 사용한다. 게임은 펠트 위의 크림색 카드처럼 읽히도록 화면을 정돈한다. 원본 카드 사진을 사용하지 않고 기하학적 경로·풍경·천체를 독자적인 SVG/CSS로 표현한다.

| 역할        | 색        | 사용                                 |
| ----------- | --------- | ------------------------------------ |
| 바탕        | `#F5F2E9` | 홈, 로비의 따뜻한 종이               |
| 종이        | `#FFFCF4` | 카드·대화상자                        |
| 잉크        | `#193C31` | 주 텍스트·버튼                       |
| 테이블      | `#203E35` | 홈의 집중 영역·게임 보드             |
| 보조 텍스트 | `#607267` | 종이 바탕의 부가 설명                |
| 새싹        | `#CEE3B2` | 현재 차례·주요 행동                  |
| 황동        | `#B89154` | 장식·작은 강조, 본문용으로 쓰지 않음 |
| 경계        | `#D9DBCE` | 종이 위 구분선                       |

색상만으로 의미를 전달하지 않는다. 경로는 패키지의 `aurora ○`, `ember △`, `tide ◇`, `moss □`, `dusk ☆` 식별 체계를 유지하고 한국어 이름도 표시한다. 모든 최종 텍스트 조합은 실제 렌더링에서 대비를 확인한다.

확정한 구현 서체는 한국어 제목에 Gowun Batang, 본문·게임 정보에 Pretendard다. 숫자는 명료한 산세리프와 tabular figures를 사용한다. 홈 제목은 데스크톱 최대 64px, 모바일 36–45px, 기본 본문은 16px이다. 폰트는 `font-display: swap`을 적용하고 배포 시 원본 라이선스를 포함한다.

실제 첫 구현 자산은 `apps/web/public/art/`에 독자 제작 SVG 다섯 장으로 제공했다. `star-trails.svg`는 세 장의 천체 카드와 게임 조각을 담은 투명 배경의 홈 장식이며, 나머지 네 파일은 후속 게임 소개용이다. 그림 속 주사위·조각은 홈의 보드게임 분위기를 위한 장식으로, 별길 탐험 규칙이나 추가 구성물을 뜻하지 않는다. 카드 숫자나 점수 같은 게임 데이터는 그림에 포함하지 않았다. 다섯 SVG를 PNG로 렌더링하여 자르기·겹침을 확인했다. 후속 개선에서 기존 독자 카드 면을 `orbit-card-ember.svg`, `orbit-card-tide.svg`, `orbit-card-aurora.svg`로 분리해 원형 테이블 위 모션그래픽에 사용했다. 기존 원본 SVG와 참고 패키지는 보존했다.

글꼴은 Gowun Batang 400/700과 Pretendard 1.3.9 가변 글꼴로 정했고 `apps/web/public/fonts/fonts.css`에서 자체 호스팅한다. Gowun Batang은 Fontsource 5.3.0의 한글·라틴 WOFF2를 그대로 사용했다. 각 글꼴의 라이선스와 다운로드 출처는 같은 디렉터리에 보존했다.

## 화면 구성

- 홈: 작은 워드마크와 단순한 내비게이션, 좌측의 큰 한국어 제목과 초대 중심 설명, 우측의 원형 초록 테이블과 독자적인 천체 카드 세 장의 궤도 구성. 가장 강한 행동은 테이블 만들기 하나다. 아래에는 첫 게임을 크게 소개하고 후속 게임은 준비 상태를 명확히 표시한다. 가상의 동접자·후기·성과 수치를 넣지 않는다.
- 내 테이블: 참여 중인 테이블과 새 테이블 만들기를 먼저 보여준다. 빈 상태에는 초대와 생성 방법을 짧게 설명한다.
- 대기실: 실제로 활성화된 두 좌석, 초대 복사, 준비 상태와 시작 조건을 한 화면에서 읽을 수 있게 한다. 배경 장식보다 이름과 준비 여부가 앞선다.
- 게임: 상대 공개 경로 → 공동 버림 더미 → 내 경로 → 내 손패의 관계를 유지한다. 현재 차례와 PLACE/DRAW 안내를 가장 잘 보이는 위치에 둔다. 선택된 카드와 가능한 목적지를 같이 강조한다. 모든 숫자·점수·기호는 HTML로 제공한다.
- 결과: 합계와 각 경로의 산식을 함께 보여준다. 재경기와 대기실 복귀 후에도 동일한 테이블이라는 연속성을 유지한다.

모바일에서는 손패만 가로 스크롤되며 페이지 자체는 360px·390px에서 가로 넘침이 없어야 한다. 작은 경로에는 마지막 숫자·지원 개수·장수·점수를 요약하고 자세한 내용은 눌러서 연다. 주요 입력 목표는 제품 기준인 44×44px 이상으로 유지한다.

## 상호작용과 검수

실제 구현은 손패 선택 160ms, 승인된 공개 카드·점수 변화 220ms로 맞췄다. 홈 카드 도착은 800ms, 미세한 상하 움직임은 7–9초, 금색 궤도는 26초로 구성한다. 홈에는 재생·일시정지 조작을 제공하고, 화면 밖과 숨긴 탭에서는 멈춘다. 시스템과 앱의 모션 감소에서는 완성된 정지 배치를 유지한다. 애니메이션이 서버 처리를 막거나 승인되지 않은 점수를 확정하지 않는다. `prefers-reduced-motion`에서는 이동을 줄이고 선택·결과 정보는 유지한다. 클릭과 키보드 조작을 기본으로 두며 드래그는 필수 입력으로 만들지 않는다.

대화상자는 명확한 제목과 닫기·취소 경로, 초기 포커스, 닫힌 뒤 포커스 복귀를 제공한다. 요청 중 중복 입력을 막고 상태를 표시한다. 연결 끊김과 서버 거절은 원인을 한국어로 설명하며 사용자 입력을 불필요하게 지우지 않는다. 공개 로그에 비공개로 뽑은 카드의 내용을 넣지 않는다.

완료 시 데스크톱과 390px·360px의 홈·대기실·게임·결과를 실제 브라우저로 확인한다. 키보드로 카드 선택과 실행, 모달 열기·닫기를 검수하고 로딩·빈 상태·오류·모션 감소도 확인한다.

## 현재 운영 범위

2026-10-23 사용자 결정으로 실제 Supabase 인증·DB 연결과 배포는 보류했다. Vercel을 기준으로 준비 사항을 기록했으며 기존 Supabase 어댑터는 아직 미연결이다. 로컬 두 브라우저 검증과 외부 운영 검증을 구분한다.

## 사용한 참조와 스킬

- [Best Free Fonts](https://bestfreefonts.com/): 영문 글꼴의 성격과 다양성을 조사했다. 글꼴 이름만 도입하지 않고 한국어 지원과 읽기 품질을 별도로 고려했다.
- [Originkit](https://www.originkit.dev/): 공개 페이지와 메타데이터를 확인했다. 페이지의 동적 갤러리는 텍스트 수집에서 제한되어 특정 컴포넌트를 검증하거나 복사했다는 주장은 하지 않는다. 움직임은 패키지의 명시된 시간과 상태 전이를 우선한다.
- [Awwwards Typography](https://www.awwwards.com/websites/typography/): 글자 크기·행 길이·여백을 통한 위계와 일관성을 참고했다. 수상작의 전체 레이아웃이나 자산을 복제하지 않는다.
- [Impeccable 공식 저장소](https://github.com/pbakaus/impeccable), [Codex SKILL.md](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/SKILL.md): 4.7.0 지침을 임시 디렉터리에서 읽고 `context`를 실행했다. 홈페이지의 설득 역할과 게임 화면의 작업 수행 역할을 구분하고, 렌더링 검수와 명확한 시각적 관점을 적용했다. 설치는 수행하지 않았다.
- [UI UX Pro Max 공식 저장소](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [SKILL.md](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md): `social board game cafe --design-system` 및 좁힌 `board game --design-system`, `keyboard focus modal --domain ux`를 실제 실행했다. 펠트 초록·황금색과 접근성 방향은 참고했다. 자동 추천의 Inter와 WebGL/3D는 한국어 제품과 DOM 기반 명세에 맞지 않아 채택하지 않았다. 검색 출력은 권위 있는 제품 명세로 취급하지 않았다.
- [Gowun Batang 원본 라이선스](https://github.com/google/fonts/blob/main/ofl/gowunbatang/OFL.txt), [Pretendard 원본 라이선스](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/dist/LICENSE.txt): 폰트 배포 시 출처·라이선스 보존 기준.

스킬은 설계와 검수를 돕는 참조이며 게임 규칙, 서버 권한, 사용자 범위의 우선순위를 바꾸지 않는다.
