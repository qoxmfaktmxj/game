# 별길 탐험 카드 일러스트

## 최종 확정과 실제 연결 · 2026-10-26

사용자가 하늘 깡총50면과 **회색 보더콜리10 v5**를 확정했다. 실제 게임의 손패·공개 길·버림·확대 및 `/cards`가 이제 계열별 대표5장 대신 카드별 확정50면을 사용한다. 대기실 대표도 같은 확정 그림을 사용한다. [현재 적용 기록](art/sky-hop-release.md), [최종 선택](art/sky-hop-final-selection.json), [커밋용 정확 생성 기록](art/sky-hop-approved-prompts.json)을 기준으로 한다. 아래는 이 연결 전에 진행한 제작·검수 이력이다.

## 2026-10-26 하늘 깡총 · 포즈 수정 16면

멍이·냥이의 지원 ×2와 숫자 2–6을 계열마다 6면씩 새 포즈로 바꾸고, 멍이 10은 **보더콜리 · 신나는 달리기**, 냥이 10은 **터키시 앙고라 · 앉아 돌아보기**로 변경했다. 물개 10은 **옆으로 기대 쉬기**, 수달 8은 팔과 손의 연결을 정리한 **포근한 포옹**이다. 이번 수정은 총 16면이며, 멍이·냥이 7–9와 랑이 10을 포함한 나머지 34면은 유지한다. 최종 카드 앞면은 여전히 50종이고 실제 덱은 60장이다.

[이번 포즈 수정 기록](art/sky-hop-pose-refresh.md)과 [최신 50면 선택 파일](art/sky-hop-final-selection.json)을 기준으로 본다. 비교 화면은 기본 보기에서 수정 16면, `#last`에서 최신 7–10의 20면, `#all`에서 최신 50면을 보여준다. 이번 수정의 브라우저 검증은 포즈 수정 기록에서 별도로 다룬다. 실제 게임은 아직 `animal-friends/{suit}.png` 대표 5장을 사용하며 새 50면을 연결한 상태는 아니다.

## 2026-10-25 하늘 깡총 확정 · 50면 제작 기록

사용자는 round-05 하늘 깡총 화풍을 선택했다. 같은 대표 그림의 반복 대신 카드별 견종·묘종 또는 행동을 원했고, **계열별3종 확인 → 3종 확인 → 4종** 순서로 진행했다. [첫15종](art/sky-hop-batch01.md), [두 번째15종과 수정본](art/sky-hop-batch02.md), [마지막20종](art/sky-hop-batch03.md)을 제작·검수해 카드 앞면50종을 모두 준비했다. 당시 마지막 멍이·냥이8장을 서로 다른 포즈로 변경했고 ‘이번8장부터 보고 결정’ 답변에 따라 이전12면을 유지했다. 그 시점의 눈 수정과 아이보리 래브라도v3를 포함한 선택은 [이전 50면 스냅샷](art/sky-hop-batch03-selection.json)에 보존한다. 이후의 16면 변경은 위 최신 기록을 따른다.

## 2026-10-25 동물 테마 첫 적용

후속 수정: 첫 카드게임부터 집중한다는 사용자 결정에 따라, 멍이4·랑이6 눈을 정돈하고 멍이5를 아이보리 래브라도로 바꿨다. [2차 비교 기록](art/sky-hop-batch02.md)의 v2 세 장을 참고한다. 다른 게임의 아트는 이번에 진행하지 않았다.

현재 첫 게임은 동물별 대표 그림 5장을 사용한다. `aurora=멍이(강아지)`, `ember=냥이(고양이)`, `tide=물개`, `moss=수달`, `dusk=랑이(아기 호랑이)`다. 토끼는 랑이로 교체했다. 내부 식별자와 60장 덱, 점수 산식은 그대로다. 표시 게임명은 후보 선택 전까지 **별길 탐험**을 유지한다.

- 현재 이미지: `apps/web/public/art/cards/animal-friends/{suit}.png`, 1024×1536 PNG 5장, 합계 약 11.17MB.
- 생성: 내장 imagegen으로 각 동물을 별도 생성했다. 원작 카드나 개인 사진을 사용하지 않았다.
- [정확한 생성 프롬프트·원본 경로·SHA-256](art/animal-friends-prompts.json).
- 현재 게임의 숫자2–10/지원50면은 여전히5개 대표 그림을 재사용한다. 별도 제작한 하늘 깡총50종은 최종 비교 화면에서 확인할 수 있으며 실제 게임 경로에는 아직 연결하지 않았다. 기존 우주/자연 그림50장도 보존했다.
- 밝은 배경의 과슈·색연필 일러스트 위에 불투명한 숫자/계열 표찰을 올린다. 지원 표시는 `×2`이며, 실제 누적 배수는 지원1/2/3장 → ×2/×3/×4이다. `2^지원장수`로 계산하지 않는다.
- 손패, 공개 길의 겹친 카드, 버린 카드, 길 상세, `/cards`에서 같은 그림을 쓴다. 이미지에 규칙 숫자를 포함하지 않는다.

아래는 **2026-10-24에 제작한 기존 테마의 기록**이다. 당시의 50개 고유 이미지 및 검증 결과를 현재 동물 대표 그림의 제작 수량으로 해석하지 않는다.

## 기존 우주·자연 테마

2026-10-24. 내장 `imagegen` 도구를 카드 그림마다 한 번씩, 총 50회 사용해 만들었다. 하나의 합성 시트를 잘라 쓰거나 원작 카드·비공개 사진을 사용하지 않았다. 생성 원본을 아래 프로젝트 경로에 복사했다.

- 저장 위치: `apps/web/public/art/cards/star-trails/`
- 파일명: `{aurora,ember,tide,moss,dusk}-{2..10,support}.png`
- 5계열 × (숫자 9종 + 지원 1종) = 고유 그림 50종
- 숫자 45장 + 같은 계열마다 동일한 그림을 쓰는 지원 3장씩 = 실제 덱 60장
- 모두 1024×1536 PNG. 원본 합계 141,292,411 bytes(약 134.7MiB).

## 화면 적용

손패와 길 상세에서 공통 `PlayingCard`를 사용하며, `/cards`에서 50종을 크게 볼 수 있다. 별길 탐험 규칙창의 **카드 그림 모아보기**는 새 탭으로 열려 진행 중인 게임을 유지한다. 작은 밝은 숫자 배지와 하단 어두운 음영으로 명암이 다른 그림에서도 숫자와 이름을 읽을 수 있게 했다.

원본 PNG는 보존한다. 웹은 Next.js Image 최적화로 표시 크기와 화면 배율에 맞춘 이미지를 전달하고 지연 로딩한다. 손패는 76–88px, 갤러리는 모바일 45vw·데스크톱 240px를 요청한다. 서버의 첫 이미지 변환에는 시간이 걸릴 수 있으며, 이 캐시와 실제 운영 서버 응답은 배포 후 확인할 항목이다.

## 검증

파일 50개의 예상 이름·PNG 해상도·SHA-256을 확인했다. 누락·불필요한 추가 파일이 없고 해시는 모두 다르다. 생성된 그림을 각각 육안 검수했으며, 브라우저에서 고유 이미지 50개의 로딩과 390px·360px 가로 넘침 없음, 모바일 숫자 표시를 확인했다. 실제 손패 선택·봇 플레이·재접속의 공통 브라우저 시험도 새 그림으로 실행한다. 최종 전체 결과는 [검증 보고서](verification-multigame.md)에 기록한다.
