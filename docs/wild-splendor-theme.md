# 와일드 스플렌더 테마

2026-10-27 사용자 확정. 기존 빛의 공방의 표시 이름은 **와일드 스플렌더**다. 내부 `workshop` 식별자와 공식 기본판 규칙은 유지하고, 이름·그림·자원 표현을 동물 성장 테마로 바꾼다. 사용자는 포켓몬판의 실제 진화 규칙 대신 기존 기본판 유지 옵션을 선택했다.

## 구성

| 내부 자원 | 표시 자원 | 계열 동물 | 표시 색 |
| --- | --- | --- | --- |
| red | 생고기 | 강아지 | 빨강 |
| blue | 연어 | 수달 | 파랑 |
| green | 캣닢 | 고양이 | 초록 |
| black | 도토리 | 카피바라 | 갈색 |
| white | 꿀단지 | 호랑이 | 노랑 |
| gold | 황금 뼈다귀 | 조커 | 금색 |

개발 카드 90장(1단계 40장·2단계 30장·3단계 20장), 후원자 10개, 비용·점수·할인, 일반 토큰 5종과 조커, 15점 종료·동점 처리 모두 기존 기본판을 유지한다. 후원자의 표시 이름은 **숲의 수호자**이고, 조건은 기존 영구 할인 수다. 사용자가 붙인 예시 비용과 성장 단계별 귀족 조건은 채택하지 않았다. 모든 동물 카드는 할인 1을 제공한다.

- 1단계: 아기 동물. 방석·둥지·포근한 안식처에서 쉬거나 장난친다.
- 2단계: 청소년 동물. 숲길·통나무·개울·언덕을 탐험한다.
- 3단계: 다 자란 어른 동물. 능선·큰 나무·강줄기·숲속에서 성숙한 모습을 보인다.
- 성장 단계는 카드의 그림과 등급이며 합성·교체·진화 행동이 아니다.
- 부엉이, 그리즐리, 흰머리수리, 코끼리, 늑대, 사슴, 큰거북, 북극여우, 고릴라, 설표가 수호자 10개를 맡는다.

## 기존 디자인 계승과 국소 토큰

[DESIGN.md](../DESIGN.md)의 Paper Club — Open Air를 그대로 따른다. 흰색·오프화이트 공통 표면, Open Air 행동·포커스 색, 자체 호스팅 Pretendard, 공통 버튼·입력·대화상자와 모바일 행 안 스크롤을 유지한다. 근거 구현은 `apps/web/app/tokens.css`와 `apps/web/app/paper-club.css`다. 동물 그림과 간식 칩은 `workshop` 콘텐츠의 확장이며 전역 디자인 토큰이나 공통 조작 방식을 바꾸지 않는다.

`apps/web/components/workshop-theme.css`의 추가 색 토큰은 `workshop` 보드 안에서 자원 구분에만 사용한다. `paper`는 해당 자원 표식의 배경, `ink`는 그 위의 글자·강조색이다.

| 자원 | 배경 토큰과 값 | 글자·강조 토큰과 값 |
| --- | --- | --- |
| 꿀단지 | `--wild-honey-paper: #fff3cf` | `--wild-honey-ink: #755012` |
| 도토리 | `--wild-acorn-paper: #f2e6db` | `--wild-acorn-ink: #71452b` |
| 황금 뼈다귀 | `--wild-joker-paper: #fff1a8` | `--wild-joker-ink: #694600` |

나머지 자원 색은 기존 의미색을 계승한다. 모든 자원은 색뿐 아니라 한국어 이름과 칩 그림으로 구분하며, 넓은 보드 표면과 공통 버튼에 자원 색을 확장하지 않는다.

## 웹 조사와 판본 구분

[코리아보드게임즈 공식 상품](https://www.koreaboardgames.com/product/detail?prdCd=PD2024002338EAXR)의 [공식 상세 이미지](https://cdnfile.koreaboardgames.com/_data/attach/202311/16/ba9477b1d354bf12ee9af83338c92da1.jpg)는 포켓몬판이 일반 1·2·3단계와 별도 희귀·전설 카드를 사용하며, 진화와 18점 종료를 적용한다고 설명한다. 별도 특수 카드를 4단계 성장으로 해석할 근거는 없다. 따라서 사용자의 “단계가 더 있다면 1단계를 안식처로”라는 아이디어는 기존 3단계를 늘리지 않고 아기 카드의 장면과 개인 영역 이름에 적용했다.

포켓몬판 수치나 원작 그림·설명문은 런타임에 넣지 않았다. 이 게임의 수치 근거는 계속 [기존 기본판 조사](game-expansion-sources.md)다.

## 그림과 공개 데이터

기본 내장 `image_gen`으로 실사화 대표그림 1개, 동물 카드 아틀라스 15개(90개 고유 장면), 수호자 아틀라스 1개(10개 고유 장면), 자원 칩 아틀라스 1개(6개)를 제작했다. 각 아틀라스의 정확한 셀을 CSS로 표시하며 원본을 자르거나 다시 그리지 않는다. 보드의 동물 카드와 수호자 그림은 3:2 비율로 표시한다. 이미지에 숫자·비용·효과를 넣지 않고 HTML로 표시한다.

- 그림: `apps/web/public/art/cards/wild-splendor/`와 `apps/web/public/art/club-wild-splendor.png`
- 정확한 생성 프롬프트: [wild-splendor-prompts.json](art/wild-splendor-prompts.json)
- 카드 ID와 아틀라스 좌표: `apps/web/lib/card-art-ready.json`
- 재생성 스크립트: `node scripts/refresh-workshop-art.mjs` (아트 메타데이터만 갱신)

기존 `workshop` 그림은 역사적 자산으로 보존하고 새 화면에서 참조하지 않는다. 서버 비공개 상태를 브라우저로 보내지 않는다. 아틀라스는 공개 카드 디자인의 묶음이며 덱의 순서나 다른 사람의 예약 카드를 담은 게임 상태가 아니다.

## 검증

- `npm run typecheck`, `npm run test:art`(3개), `npm run build` 통과.
- `npm test`: 서버 59개와 게임 코어 108개 통과. 운영 PostgreSQL 통합 1개는 별도 환경이 없어 조건부 생략.
- 브라우저 시나리오 4개 통과: 사람 1명+봇 3명 한 라운드, 4명 초대·자원 획득·비공개 예약·새로고침 복구, 같은 테이블 게임 전환, 갤러리 그림 100개 로딩. 360/390px 가로 넘침도 검사했다.
- 수정 후 4브라우저 초대·예약·재접속 시나리오를 다시 실행하고 카드 선택 패널·규칙 창을 추가 확인했다. 데스크톱/모바일, 홈/게임/갤러리 실제 렌더 캡처를 확인했다. 독립 최종 시각 검토에서는 캡처 12장을 검토했고, 중대한 발견 사항 없이 출시 가능으로 판정했다.
- 서버/SDK 자연 종료는 자동 테스트 범위에 포함되나, 이번 브라우저 작업은 초기 행동·재접속·한 라운드 검증이다. 두 브라우저 자연 종료, 외부 인증, 운영 DB, 원격 배포를 새로 검증했다고 주장하지 않는다. 원격 배포는 사용자 오픈클로에서 별도로 수행한다.
