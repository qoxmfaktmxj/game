# 웹 자산 경량화와 토큰 표시

2026-10-27 사용자 요청에 따라 현재 그림의 선명함을 유지하면서 전송량과 배포 용량을 줄였다. 원본 PNG, 확정 선택 목록과 해시는 보존한다.

## 웹용 이미지

- `npm run assets:web`: Sharp 0.35.5로 현재 카드 281면과 대표그림 5개만 고화질 WebP로 생성한다.
- 카드 최대 폭 768px, 표지 최대 폭 1280px, WebP 품질 90. 작은 원본은 확대하지 않는다.
- 와일드 스플렌더의 아틀라스는 기존 좌표를 그대로 사용해 개별 카드로 분리한다. 한 장을 표시할 때 다른 동물 장면까지 다운로드하지 않는다.
- 원본 경로와 카드 ID를 `apps/web/lib/web-assets.json`의 내용 해시가 붙은 URL에 연결한다. 파일명 변경으로 브라우저의 오래된 캐시를 구분한다.
- 화면 크기에 따른 추가 축소는 Next.js Image가 담당한다. 게임 카드 품질은 85다.
- 웹용 이미지 286개는 총 37.90 MiB다. 기존 public/art 원본과 이전 그림 전체는 863.20 MiB다.

## 글꼴

- 자체 호스팅 Pretendard의 가변 굵기 100-900과 기존 지원 문자 14,336개를 보존한다.
- 현재 UI 문자와 일반 라틴 문자를 공통 파일로 묶고, 나머지는 256개 단위의 구간으로 분할한다. 닉네임의 드문 글자도 필요한 구간을 추가로 받을 수 있다.
- `unicode-range`로 필요한 파일만 요청한다. 홈에서 글꼴 본문은 2,057,688 bytes에서 116,692 bytes로 감소했다. CSS는 연속된 문자 범위를 묶어 별도로 압축 전 약 22KB다.
- 더 이상 사용하지 않는 Gowun Batang과 전체 Pretendard 원본은 배포에서 제외한다. 원본과 라이선스는 저장소에 남긴다.
- 재생성: `python -m pip install "fonttools[woff]==4.62.1"`, `python scripts/subset-web-font.py`. 일반 앱 빌드에는 Python이 필요 없다.
- UI에 문자가 추가되더라도 나머지 구간이 해당 문자를 지원한다. 공통 구간을 갱신하려면 위 스크립트를 다시 실행한다.

## 배포

- 웹 빌드 마지막에 `scripts/stage-web-public.mjs`가 `.web-public`을 생성한다. 현재 이미지 manifest와 글꼴 manifest에 있는 파일, CSS, Pretendard 라이선스만 복사한다.
- Docker는 원본 public 대신 `.web-public`을 최종 이미지에 복사한다. 빌드 context에서도 `public/art` 원본과 미사용 글꼴은 제외한다.
- 최종 public은 343파일, 40.50 MiB다. 이미지와 글꼴 파일 묶음의 크기이며 서버 이미지 전체 크기는 아니다.
- 이미지 변환에 필요한 Sharp 네이티브 라이브러리가 standalone 출력에 누락되지 않도록 명시적으로 포함한다. Windows 운영형 실행에서 DLL 누락과 원본 반환을 재현한 뒤 수정했다.
- 원격 Docker Compose 실행과 배포는 기존 결정대로 오픈클로에서 진행한다. 이 변경에는 DB migration이 없다.

## 와일드 스플렌더 표시

- 흰 표면과 공통 Open Air 셸을 유지한다. 게임 자원만 선명한 꿀색, 파랑, 초록, 빨강, 갈색, 금색으로 구분한다.
- 토큰은 원형 칩과 간식 도형을 공통으로 사용한다. 황금 뼈다귀도 같은 형태다.
- 비용의 자원 약칭을 제거하고 토큰과 숫자만 표시한다. 접근 가능한 이름과 툴팁에는 전체 이름을 유지한다.
- 카드 왼쪽 위는 점수, 오른쪽 위의 토큰 하나는 해당 색 영구 할인 1, 아래 토큰과 숫자는 구매 비용이다.
- 보관소와 안식처는 실제 개수만큼 칩을 겹쳐 놓는다. 0개는 빈자리를 옅게 표시한다.
- 서버가 보유량 변경을 확정하면 가져오기, 지불, 반환 방향으로 토큰 이동을 보여준다. 모션 감소 설정과 재접속 초기 동기화에서는 움직이지 않는다.

## 규칙 재확인

[Space Cowboys 공식 기본판 규칙](https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/10/SCSPL01EN_SPLENDOR_RULES_LIGHT.pdf)의 2쪽과 [사용자 제공 WING 설명](https://www.wingboardgame.com/2022/01/splendor.html)을 확인했다. 나무위키는 직접 접근에 실패했으므로 읽었다고 간주하지 않았다.

- 모든 단계의 개발 카드는 해당 색 할인 1을 준다. 같은 색 3장은 매 구매에 3 할인이다. 할인 자체는 소비되지 않는다.
- 카드 점수와 할인은 별개다. 높은 단계가 할인 2나 3을 주는 것은 기본판 규칙이 아니다.
- 귀족은 표시된 색의 할인 수를 요구하며 토큰을 지불하지 않는다. 한 차례에 최대 하나, 3점이다.
- 서로 다른 색 3개 또는 은행에 4개 이상 있는 한 색 2개를 가져온다. 예약 최대 3장, 예약 시 남아 있으면 황금 토큰 1개를 받는다.
- 차례 종료 시 토큰은 황금을 포함해 최대 10개다. 15점 이상이면 라운드를 끝까지 진행하고 점수를 비교한다. 동점은 구매 카드 수가 적은 쪽, 다시 동점이면 공동 승리다.
- 첨부한 포켓몬판은 시각 배치 참고로만 사용했다. 해당 판의 진화, 복수 아이콘 효과와 종료 규칙은 기본판에 섞지 않는다.

서버의 해당 판정과 기존 테스트를 재검토했고 규칙 코드 변경은 필요하지 않았다. 단계별 할인 1과 누적 할인 유지 회귀 검사를 추가했다.

## 실행한 검증

- 전체 워크스페이스 타입 검사와 최종 프로덕션 빌드 통과.
- `npm test` 성공. 운영 PostgreSQL 통합 1개는 별도 DB가 없어 조건부 생략.
- 추가 회귀 검사를 포함한 스플렌더 규칙 테스트 11개 통과.
- 원본 확정 그림과 새 배포 파일 검사 5개 통과. 원본 그림 해시 보존 확인.
- 브라우저 7개 시나리오 통과: 카드 갤러리 5종, 4명 초대/자원/예약/재접속/모바일/토큰 이동, 운영형 홈 자산 요청.
- 꿀단지 3개 표시, 2개 가져오기 이동, 모션 감소 시 이동 없음 확인.
- 360px와 390px에서 가로 넘침 없음. 데스크톱과 모바일 실제 캡처 검토.
- 로컬 standalone 운영형 서버에서 홈 이미지 8개 본문 합계 101,362 bytes, 글꼴 본문 116,692 bytes 확인. 화면 1036x743, DPR 1.25 기준이며 전체 페이지 전송량이나 인터넷 속도 측정은 아니다.
- 요청 폭 256px에 실제 반환 이미지 폭 256px 확인. 이전 그림과 확정 원본 PNG 주소 모두 404 확인.
- 디자인 검사기 advisory 6개는 이 게임의 기존/요청된 밀도에 관한 글자 크기와 모서리 수치다. 적용 범위를 DESIGN.md에 기록했다. 본문과 칩의 색 대비를 확인하고 꿀색을 #b45b00으로 보정했다.
- 실제 리눅스 Docker 이미지 빌드, 운영 DB, 외부 인증과 원격 배포는 이 검증에 포함하지 않는다.
