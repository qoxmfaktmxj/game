## 조사 범위와 최근성

아래 19곳을 2026-10-23에 직접 열어 확인했다. `화면`은 브라우저에서 실제 렌더링을 관찰했다는 뜻이고, `원문`은 제공된 페이지 본문·구조를 확인했다는 뜻이다. 서비스 전체를 가입해 사용하거나 모든 모바일 상태를 시험했다는 뜻은 아니다. 출시일이 없는 운영 사이트는 **현재 운영 화면**으로만 분류했다. 검색엔진의 수집일과 디자인 출시일을 같게 취급하지 않았다.

Awwwards 일부 페이지는 웹 텍스트 도구에서 접근이 실패하여 브라우저로 직접 확인했다. 수상일은 Awwwards의 해당 등록 원문에서 확인했다. FunTech는 조사일 현재 **후보작**이며 수상작으로 부르지 않는다. 전반적인 ‘2026 디자인 트렌드’를 통계로 검증한 조사는 아니다. 아래 선택과 적용은 링구링구에 맞춰 내린 디자인 판단이다.

## 현재 화면이 차분하게 보이는 이유

기존 홈 캡처에서 명조 제목의 가는 획, 넓은 행간, 저채도 크림·초록·황동, 얇은 경계선이 한 방향으로 작용한다. 정돈되어 있지만 보드게임의 선택·경쟁·친구 초대보다 독서나 라이프스타일 서비스의 분위기를 먼저 전달한다. 실제 게임을 고르는 부분은 첫 화면 아래에 있고, 첫 화면은 범용적인 감성 문구와 카드 세 장이 차지한다. 다음 개선은 애니메이션을 더 많이 넣는 것보다 **게임과 행동의 우선순위를 바꾸는 것**에 집중해야 한다.

- 제목은 굵은 산세리프로 바꾸고 줄 수와 행간을 줄인다. 감성 문구와 제품 설명을 한꺼번에 길게 쌓지 않는다.
- 첫 화면 안에서 대표 게임, 게임 선택, 테이블 만들기의 관계가 보이게 한다.
- 공통 셸은 절제하고 게임별 포스터에는 서로 다른 색·큰 도형·제목 비율을 준다.
- 아트는 작은 디테일을 늘리기보다 큰 링·카드·토큰의 실루엣을 선명하게 한다.
- 게임 화면에서는 장식보다 차례, 합법적인 다음 행동, 숫자, 연결 상태를 우선한다.

## 방향 제안

### A. Ring Club — 추천

친구들이 들어와 테이블을 고르는 작은 게임 클럽. 거의 검은 청록/네이비 바탕에 크림색 큰 제목, 라임색 주요 버튼, 살구·라일락·하늘색 게임 포스터를 둔다. 기존 고리 로고를 조금 굵게 만들고 큰 링 두 개가 카드와 타일의 무대를 형성한다. 첫 게임 아트의 천체 요소는 남기되 빈티지 인쇄물의 느낌은 줄인다.

제안값은 canvas `#101820`, surface `#1B2631`, text `#F4F4EC`, accent `#D6F55B`다. 실제 적용 전 바탕별 텍스트·포커스 대비를 검증한다. 브랜드는 짙고 게임 카드는 밝게, 게임 진행판은 별도의 안정된 톤으로 정돈한다. 이는 현재 `DESIGN.md`의 크림·초록 유지 원칙과 충돌하는 **의도적인 새 방향 제안**이다. 채택 시 문서도 구현에 맞춰 갱신해야 한다.

좋은 이유: Discord의 친구 중심 분위기, PlayStation의 아트 중심 선택, Chess.com의 짧은 시작 동선을 한 제품 안에서 자연스럽게 결합할 수 있다. 흑색 배경만으로 세련됨을 주장하지 않고 타입·크기 차이·정보 순서로 완성한다.

### B. Colour Table

밝은 아이보리 바탕은 유지하되 명조를 굵은 산세리프로 바꾸고, 적은 수의 큰 컬러 포스터와 납작한 그래픽을 사용한다. 링·타일·칩은 장난감처럼 둥글고 단단하게 표현한다. Nintendo/Poki의 명료한 색 분리를 참고하되 작은 썸네일을 과도하게 늘리지 않는다. 모바일 친근함을 가장 중시할 때 적합하다.

### C. After Hours

짙은 잉크 바탕에 구리·백색·청록만 사용하고 실제 카드의 촉감과 테이블 조명을 강조한다. 더 성숙하고 몰입감 있는 보드게임 라운지다. 세련되지만 여러 장르의 즐거움과 ‘링구링구’ 이름의 경쾌함이 약해질 수 있어 A보다 우선순위가 낮다.

## 모션 설계

홈에서 시선을 끄는 장면은 하나로 제한한다. 큰 링이 천천히 움직이고 게임 도구가 등장하는 장면을 쓰되, 목록·본문까지 계속 움직이지 않는다. 카드 선택은 160–220ms, 대기실 준비 완료는 짧은 링 완성, 화면 전환은 250–350ms 정도의 시작값으로 잡는다. 플레이 상태는 서버 승인 시점에 바뀌며 애니메이션 완료를 기다리지 않는다.

모션 감소·탭 비활성·화면 밖 일시정지·수동 정지를 보존한다. 숫자가 이동하거나 요동해서 읽기를 방해하지 않도록 한다. 터치에서는 마우스 추적 효과를 요구하지 않고 같은 정보와 행동을 제공한다. 승리·완료 효과는 짧고 재실행되지 않아야 한다.

## 다음에 받으면 가장 도움이 되는 레퍼런스

많은 링크보다 아래 네 종류를 **각각 1개씩**, 좋아하는 지점을 한 문장으로 붙여 받으면 방향을 빨리 좁힐 수 있다.

1. **전체 분위기:** ‘이 사이트의 어두운 바탕과 굵은 제목이 좋다’처럼 색·톤을 지정한 홈 화면.
2. **게임 목록:** 게임 이미지가 어느 정도 크고, 설명이 얼마나 보이면 좋은지 판단할 수 있는 목록 화면.
3. **실제 플레이 화면:** 카드 크기, 플레이어 위치, 손패·버튼 배치 중 무엇이 편한지 표시한 화면.
4. **움직임:** 카드 뒤집기나 장면 전환 한 가지가 보이는 짧은 영상/정확한 URL과 해당 구간. ‘느리고 묵직하게’ 또는 ‘짧고 통통하게’ 같은 속도 취향.
5. **피하고 싶은 것 한 가지:** 지나치게 유아적, 카지노 같음, 과도한 네온, 긴 인트로처럼 명확한 금지 취향.

예: ‘Discord 같은 친구들 공간의 느낌, PlayStation처럼 큰 게임 포스터, Chess.com처럼 단순한 시작 버튼. 네온은 적게, 클릭할 때만 통통한 움직임.’ 이 정도면 하나의 구현 가능한 방향이 된다.

## 구현 반영 — 2026-10-24

위 제안 중 Ring Club을 채택해 `apps/web/components/home.tsx`, `apps/web/app/globals.css`, `apps/web/components/multigame.css`에 반영했다. `DESIGN.md`와 `.impeccable/design.json`도 실제 새 색상·타입·컴포넌트에 맞춰 갱신했다. 제안 당시의 크림·초록 방향과 충돌한다는 설명은 이전 상태에 대한 기록이다.

다섯 게임 커버는 외부 사이트의 이미지를 가져오지 않고 imagegen으로 새로 제작했다. `apps/web/public/art/CLUB_ART_SOURCES.md`에 출처와 파일 매핑을 기록했다. 첫 화면은 큰 링 장면, 굵은 한글, 다섯 게임 선반으로 바꿨고, 그림의 이동과 궤도 선은 화면 밖·탭 비활성·수동 정지·모션 감소 설정에서 멈춘다. 플레이 화면은 숫자와 승인된 게임 상태를 HTML로 표시한다.

디자인 작업에서 직접 실행한 검증은 기존 첫 게임 E2E 5개 통과와 공방·가든·의회·신호 다인 브라우저 E2E 4개 통과다. 360px·390px의 홈/규칙 창, 게임 진행 화면, 연결 복구와 같은 테이블 재경기를 포함한다. 다섯 게임의 데스크톱·모바일 캡처를 열어 확인했고, 상대 차례에 공개 카드 숫자가 흐려지던 문제와 게임별 제목 CSS 우선순위 문제를 수정했다. 홈 대표 캡처는 `artifacts/verification/ring-club-2026/`, 첫 게임 검증은 `artifacts/first-game-e2e/`, 공방·가든 수정 후 캡처는 `artifacts/design-game-e2e/`, 의회·신호 최종 레이아웃 캡처는 `artifacts/design-extra-game-e2e/`에 있다.

Impeccable 검사는 강제 교정 항목 없이 끝났지만, 보존된 기존 CSS를 포함해 색·글자 크기·반경이 문서 토큰과 정확히 일치하지 않는 권고 항목은 남아 있다. 이 기록을 접근성 전체 인증이나 외부 로그인·DB·배포 검증으로 해석하면 안 된다. 전체 기능 검증 결과는 프로젝트의 최신 검증 보고서를 따른다.
