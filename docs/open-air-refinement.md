# 흰 표면과 Open Air 후속 정리

작업일: 2026-10-27.

## 사용자 결정과 범위

사용자는 기존 구성을 유지하면서 초록 기가 도는 색 대신 정말 흰색에 가까운 오프화이트를 원했다. 하나의 포인트색을 정하자는 요청 뒤 **PANTONE 15-3922 Open Air**를 선택했다. 링구링구의 기존 두 고리 아이콘 교체, 안내 버튼 `좋아요, 알겠어요`를 `닫기`로, `준비됐어요`를 `준비`로 바꾸는 요청도 함께 반영한다.

같은 날 비교 시안을 확인한 뒤, 사용자는 첫 게임의 표시 이름을 정확히 **로스트 팻츠**로 정하고 대표그림은 **B안**을 선택했다. B안은 숫자 2–10의 3×3 배열과 오른쪽 큰 `×2` 수달 카드다. 이 확정은 아래의 미선택 후보·시안 기록을 대체한다.

현재 시각 기준은 [DESIGN.md](../DESIGN.md)와 `apps/web/app/tokens.css`다. [첫 Paper Club 구성](paper-club-redesign.md)과 [Ink and Vermilion 색감](ink-club-restyle.md)은 이전 결정과 검증의 역사로 남긴다. 새 팔레트 선택은 앞선 차콜·녹슨 주홍 제안을 대체하며, 기존의 누런 베이지 `#F4F1EA`·`#E7E3D9`를 되돌리지 않는다.

이번 구현은 공통 CSS 색, SVG 브랜드 아이콘, 두 버튼의 문구와 첫 게임의 표시 이름·대표그림을 바꾸는 작업이다. 원본 명세에서 별길 탐험으로 부르는 게임을 현재 서비스에서는 로스트 팻츠로 표시한다. 내부 `star-trails`, 라우트·이벤트·READY 상태 전환·서버 View·규칙 함수는 유지한다. 카드 그림의 계열색·자원색에는 게임 의미가 있으므로 앱 바탕처럼 일괄 탈색하지 않는다.

## 색의 출처와 적용

사용자가 고른 색상명과 번호는 [Pantone 공식 색상 조회 항목](https://www.pantone.com/eu/de-de/color-finder/15-3922-tcx)의 `15-3922 TCX Open Air`와 대응한다. 공식 페이지의 검색 정보로 이름을 확인했지만, 본문 직접 접근은 403으로 실패했고 공식 디지털 색상 데이터는 확보하지 못했다. **공식 Pantone HEX를 검증한 것으로 표현하지 않는다.**

앱의 `#94B2DF`는 [Colorxs의 Open Air 자료](https://www.colorxs.com/color/pantone-15-3922-tcx-open-air)에 표시된 HEX를 디지털 근사값으로 채택한 것이다. 화면의 sRGB 색과 물리적인 Pantone 표준의 일치, 인쇄 색 재현은 이번 검증 대상이 아니다. 아래의 어두운 글자·포커스·호버 값은 앱에서 읽기와 상태 구분을 위해 정한 파생색이며 별도의 Pantone 공식 색이 아니다.

| 역할 | 실제 토큰 | 값 |
| --- | --- | --- |
| 전체 바탕 | `--color-canvas` | `#fafafa` |
| 카드·입력·대화상자 | `--color-paper` | `#ffffff` |
| 보조 표면 | `--color-paper-2` | `#f4f4f4` |
| 비활성 표면 | `--color-paper-3` | `#e9e9eb` |
| 본문 / 보조 글자 | `--color-ink` / `--color-muted` | `#252528` / `#66666c` |
| 경계 / 입력 경계 | `--color-rule` / `--color-border-strong` | `#e3e3e6` / `#85858c` |
| 주요 버튼·브랜드 채움 | `--color-accent` / `--color-brand` | `#94b2df` |
| 버튼 호버 | `--color-accent-hover` | `#83a5d6` |
| 강조색 위 글자 | `--color-accent-ink` | `#182b45` |
| 링크·상태 글자·필수 윤곽·포커스 | `--color-accent-text` / `--color-focus` | `#345884` |
| 선택·준비 완료의 옅은 배경 | `--color-accent-soft` | `#f0f5fc` |
| 카드 경계 | `--color-card-edge` | `#d4d4d9` |

큰 바탕과 패널을 파랗게 물들이지 않고 흰색·밝은 회색으로 유지한다. 밝은 Open Air는 버튼·브랜드 채움에 사용하고, 그 위 글자는 짙게 표시한다. 흰 바탕에서 읽어야 하는 작은 글자와 키보드 포커스에는 더 짙은 같은 계열색을 쓴다. 준비·선택은 색과 함께 기존 문장·아이콘·윤곽으로 표현한다. 오류는 기존 붉은 의미색을 유지한다. 색 대비 검사의 실제 수치는 아래 검증에 기록한다.

## 링구링구 아이콘

기존의 겹친 두 고리는 사용자의 요청에 따라 제거하고, **함께 펼친 카드 두 장**을 나타내는 자체 SVG 표식으로 교체한다. 뒤 카드는 흰색이고 앞 카드는 Open Air 채움이다. 서로 다른 각도로 기울인 둥근 직사각형과 두 개의 작은 카드 무늬를 사용한다. 작은 크기에서도 경계가 읽히도록 짙은 같은 계열색의 윤곽을 둔다.

- 앱 헤더·갤러리: `apps/web/components/primitives.tsx`의 공통 `Logo`.
- 브라우저 아이콘: `apps/web/app/icon.svg`.
- 링구링구 글자, 기존 마침표, 버튼의 접근 가능한 이름과 이동 동작은 유지한다.

브랜드 표식은 서비스의 카드게임 성격을 나타낼 뿐 실제 덱의 카드 수치나 구성 근거가 아니다. 외부 게임의 로고나 그림을 복사하지 않았다.

## 문구 변경

| 위치 | 이전 | 현재 | 유지하는 동작 |
| --- | --- | --- | --- |
| 대기실 준비 전 버튼 | `준비됐어요` | `준비` | 기존 READY 명령, 준비 여부 토글 |
| 게임 설명 하단 버튼 | `좋아요, 알겠어요`와 체크 아이콘 | `닫기` | 설명 대화상자 닫기 |
| 첫 게임 표시 이름 | `별길 탐험` | `로스트 팻츠` | 내부 `star-trails`와 기존 게임 규칙 |

준비 후 `준비 완료 · 취소`와 재경기 관련 별도 문구는 변경하지 않는다. 설명 하단은 동의를 뜻하던 체크 아이콘도 제거하고 닫기 동작을 직접 표시한다. 상단 X 버튼, Escape, 대화상자 안의 키보드 순환과 닫은 뒤 포커스 복귀는 기존 구현을 따른다.

기존 브라우저 테스트의 준비 버튼 이름을 새 표시 문구에 맞췄다. 설명창은 상단 X와 하단 버튼이 모두 접근 가능한 이름 `닫기`를 가지므로, 하단 버튼 검사는 대화상자 내부에서 실제 보이는 `닫기` 문구가 있는 버튼을 선택한다. 검사를 통과시키기 위해 동작 검증을 삭제하거나 약화하지 않는다.

## 게임명·표지 비교와 최종 선택

처음에는 게임명 후보 10개와 다음 표지 구성을 검토용으로 제시했다. 이후 사용자가 **로스트 팻츠**와 **B안**을 확정했다.

| 시안 | 구성 | 현재 상태 |
| --- | --- | --- |
| A | 숫자 2–10을 담은 3×3 카드 배열 | 비교 기록으로 보존 |
| B | 숫자 2–10의 3×3 배열과 오른쪽 큰 `×2` 수달 카드 | 2026-10-27 사용자 확정 |
| C | `×2`를 포함한 10면을 담은 2×5 카드 배열 | 비교 기록으로 보존 |

현재 서비스의 표시 이름은 **로스트 팻츠**이며, 확정 대표그림의 경로는 `apps/web/public/art/club-lost-pets.png`다. 원본 명세·과거 제작 기록에 남은 별길 탐험은 같은 게임의 이전 이름이다. 내부 `star-trails`, 확정 동물 50면과 60장 덱, 지원 배수·점수·카드 배치 규칙은 유지한다. B안은 기존 동물 그림을 홍보용으로 조합한 표지이며 새로운 게임 카드 데이터가 아니다.

제시했던 이름 후보는 꼬리길, 하늘깡총, 차곡차곡 동물원, 발맞춰, 한 장 한 걸음, 꼬리꼬리, 구름발자국, 동물친구 원정대, 꼬리 따라, 다섯 친구의 산책이었다. `꼬리길`을 우선 추천했던 제안은 기록으로만 남기며, 현재 확정 이름은 사용자가 직접 정한 **로스트 팻츠**다.

## 검증

### 색·아이콘·버튼 문구와 비교 시안 단계

다음은 이름·B안 대표그림의 서비스 적용 전에 실제 실행한 검증이다. 로컬 기록은 `.scratch/open-air-refinement/`에 있다.

- 전체 워크스페이스 타입 검사와 최종 프로덕션 빌드 통과.
- 기존 Playwright 12개 통과(1.4분): 준비·취소·닫기와 포커스, 두 브라우저 자연 종료·재접속·재경기, 네 추가 게임·봇, 360/390px 폭과 드래그 조작.
- 실제 렌더 확인: 홈 바탕 `rgb(250,250,250)`, 버튼 `rgb(148,178,223)` / 글자 `rgb(24,43,69)`, 새 SVG마크의 두 카드, 가로 넘침·깨진 이미지 없음.
- 공통 팔레트 12조합 대비 통과. 주 버튼 6.59:1, 호버 5.66:1, 보조 글자 5.19:1, 포커스 6.64:1. 설명창 범례도 밝은 표면용 기존 계열색으로 연결했다. 전체 서비스 접근성 인증을 뜻하지 않는다.
- Hallmark 28파일+홈: 0 FAIL, 0 REFLEX, 7 WARN. 사용자가 고른 실제 흰 표면과 Open Air에 유사한 기존 아트의 색면 검출은 기록된 예외다. 남은 WARN은 실제 자원격자·작은 역할 배지·기존 여러줄 빈상태·정적 버튼패턴 추정이다.
- 세 표지 시안은 실제 확정 아트로 만들고 번호·개수·이미지 로딩·390px 가로 폭을 검사했다. A는 9장, B와 C는 숫자9장과 지원1장이다. 비교 화면 `index.html`과 비교 이미지 `overview.png`는 로컬의 `.scratch/open-air-refinement/cover-studies/`에 보관한다.
- 이 단계에서는 게임명·표지를 비교 자료로 검증했으며, 확정 이름·B안의 서비스 적용 검증과 구분한다.

### 로스트 팻츠 이름·B안 대표그림 적용

확정 이름과 B안의 서비스 적용 후 다음 검증을 별도로 실행했다. 브라우저 기록은 `.scratch/open-air-refinement/lost-pets-e2e/`에 있다.

- 전체 워크스페이스 타입 검사와 `npm run build` 통과.
- 기존 `table-play`, `multigame`, `bots` Playwright 테스트 11개 통과(1.3분). 첫 게임과 추가 게임·봇의 기존 동작 검사를 새 표시 이름으로 실행했다.
- 홈 1440px, 대기실 360px·390px 실제 렌더에서 B안의 숫자 카드 9장과 오른쪽 `×2` 수달 카드가 잘림 없이 표시되는 것을 확인했다.
- 실행 코드의 TS/TSX에서 이전 표시 이름과 새 이름의 오타가 남지 않은 것을 확인했다. 내부 `star-trails`와 기존 규칙, 확정 동물 50면은 유지한다.
- 프로덕션 `apps/web/public/art/club-lost-pets.png`와 선택한 B안 원본의 SHA-256이 같아 파일 복사 과정에서 이미지가 바뀌지 않았음을 확인했다.

외부 인증·PostgreSQL·운영 배포의 실제 검증은 로컬 화면과 브라우저 검증 범위와 구분한다.
