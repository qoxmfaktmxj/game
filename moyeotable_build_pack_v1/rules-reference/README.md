# 첫 게임 규칙 참조 코드

Node.js 20 이상에서 의존성 설치 없이 실행합니다.

```sh
cd rules-reference
npm test
```

40개 테스트에는 100판 seeded 자동 진행이 포함됩니다. 덱의 마지막 장을 매 턴 메인 덱에서 뽑는 시나리오로 한 판당 88개 명령(44차례)을 수행합니다. 모든 가능한 전략/대화형 버림 회수 루프를 증명하는 형식 검증은 아닙니다.

`engine.mjs`는 순수 규칙 참조 구현이며 `server-random-example.mjs`는 Node.js crypto로 불투명 카드 ID·안전한 셔플·선공을 주입하는 예시입니다. 기본 `createDeck()`의 TEST ID는 고정 테스트용이므로 서버에서 그대로 사용하지 않습니다.

아직 없는 것: 인증, Room, 실제 네트워크, DB 트랜잭션, 프로토콜 런타임 검증 통합, 중복 명령 처리, 기권·이탈, 클라우드 배포입니다. contracts/game-module.ts의 통합 인터페이스로 옮기면서 validateCommand 어댑터와 서버 저장 경계를 구현해야 합니다.

테스트 파일은 정상/거절 행동·점수·불변식·비밀 정보 View를 검증합니다. 운영 환경용 보안 감사나 전체 멀티플레이 제품 인증을 대신하지 않습니다.
