# 후속 이미지 제작 프롬프트
이 문서는 다음 생성 작업의 입력이다. 아래 이미지 전체가 현재 패키지에 생성되어 있다는 뜻이 아니다.

## 공통 스타일
독자적인 하늘 관측·자연 패턴을 소재로 한 성숙한 보드게임카페. 어두운 잉크색과 크림색, 은은한 민트/황동 포인트. 과도한 판타지 장식 대신 명확한 형태와 부드러운 질감. 실제 상용 보드게임의 카드/캐릭터/로고/레이아웃을 재현하지 말 것. 글자·숫자·워터마크 없음. 새 캐릭터를 쓰더라도 기존 IP와 닮지 않게.

## home-background / 1920×1080
저녁의 아늑한 테이블 라운지, 창밖에 추상적인 별빛, 비어 있는 나무 테이블, 조용한 조명, 사람 없음. 왼쪽 45%는 제목을 얹을 수 있도록 낮은 대비와 단순한 형태로 비워두기. 게임 로고나 카드 그림이 보이지 않게. 가로형.

## table-background / 1920×1080
위에서 수직으로 내려다본 짙은 녹청색 펠트 테이블, 가장자리에 미세한 나무 프레임. 중앙 80%는 균일하고 조용한 질감. 카드·토큰·텍스트·손 없음. 반복 패턴 없이 UI 가독성을 우선.

## star-trails-cover / 1200×800
다섯 개의 추상적인 빛 길이 밤하늘의 관측 지점으로 이어지는 독자적 일러스트. 카드·게임판·기존 탐험 테마 유적 없음. 낮은 지평선과 넓은 하늘, 작은 빛의 포인트. 제목은 나중에 HTML로 렌더링.

## 다섯 경로 카드 일러스트 / 각768×1024
aurora: 부드러운 오로라의 원형 흐름. ember: 해 질 무렵 세 갈래 빛. tide: 달빛 수면의 마름모 반사. moss: 밤의 사각 온실과 작은 식물. dusk: 다섯 갈래 별빛이 흐르는 하늘. 모두 같은 화풍/광원/여백. 상하 18%는 숫자·기호 UI를 얹을 빈 공간, 얼굴·손·글자 없음. 한 장씩 생성하고 같은 계열의 구도를 유지.

## card-back / 768×1024
회전해도 방향을 알기 어려운 상하 대칭 추상 천문 패턴. 중앙 원과 별의 선형 조합, 크림 선과 짙은 녹청 바탕. 색상별 카드 정체가 드러나지 않는 단일 공통 뒷면. 텍스트 없음.

## 후속 게임 커버
빛의 공방: 광학 장치와 빛 조각의 공방. 밤의 의회: 밤 도시의 불 켜진 회의 창. 황혼의 신호: 사막 관측소의 안테나와 신호. 넘버가든: 숫자를 넣지 않은 추상 타일 정원. 모두1200×800, 글자/원작 인물/원작 아트 없음.
