# G3~G4 화면
prototype/index.html과 visuals/는 배치 참고용이다. 실제 구현은 Next.js + React + TypeScript + Motion으로 하고 서버 PlayerView만 사용한다. 홈·로비·대기실·게임·결과를 구현한다. 모바일은 카드 선택→대상 터치가 기본이며 드래그는 필수가 아니다.

서버 연결 전 mock transport를 분리하고 제품 코드와 섞지 않는다. 390px에서 페이지 가로 넘침을 없애고 손패 내부만 스크롤한다. 내 차례/상대 차례/DRAW/저장 중/연결 끊김/거절/결과/무효 종료를 모두 구현한다. 이미 공개된 행동을 임의 undo하지 않는다. 폰트 파일을 이 패키지에서 찾거나 외부로 복제하지 않는다.
