# 개발 AI 시작 프롬프트
이 폴더를 기준으로 공개 웹사이트 + 친구 초대형 무료 보드게임카페 '모여테이블'(가칭)을 개발한다. 먼저 START_HERE.md, AGENTS.md, docs/00_decisions.md, docs/03_architecture.md, docs/04_data_protocol.md, docs/05_game01_star_trails.md를 읽어라.

첫 작업 범위는 G0~G1이다. 온라인 서비스 전체나 다섯 게임을 한 번에 만들지 마라. 제안 모노레포를 만들고 strict TypeScript로 첫 게임 규칙 모듈과 타입, 단위 테스트를 구현하라. rules-reference/는 의미를 검증한 참고 코드이며 그대로 완성 서버로 간주하지 마라. 이후 단계는 docs/08_backlog.md의 완료 조건을 따라라.

시작 전에 (1) 결정 기준 10개 (2) 변경할 폴더 (3) 검증 명령 (4) 아직 구현하지 않을 범위를 짧게 적어라. 이어 실제 파일을 작성하고 테스트하라. 테스트 결과, 실패/미검증 항목을 보고하라. references/ 원작 사진을 런타임에 포함하지 마라. 임의의 통합 성공/배포 성공을 주장하지 마라.
