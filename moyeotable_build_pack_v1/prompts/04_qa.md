# 출시 전 검수
완료를 주장하기 전에 docs/07_test_release_ops.md를 기준으로 실제 검증한다. 두 로그인 계정과 두 브라우저로 자연 종료·동점·기권·재경기·모바일·브라우저 새로고침·서버 재시작을 시험한다.

DevTools 소켓/HTTP 응답에서 상대 손패·전체 덱·비밀 seed·초대 토큰 해시가 노출되지 않는지 점검한다. 동일 commandId 재전송, 같은 version 동시 명령, DB 저장 실패, ACK 유실을 시험한다. 결과는 실행/실패/미실행으로 구분하고 실패를 삭제하거나 통과로 포장하지 마라. 공개 빌드에 references/가 없는지 검사하라.
