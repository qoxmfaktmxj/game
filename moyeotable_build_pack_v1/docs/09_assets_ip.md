# 09. 이미지·에셋·권리 관리

## 포함 자료를 구분
1. `references/ai_concept_original.png`: 앞선 대화에서 만든 AI 콘셉트 원본. 전체 분위기 참고용이며 문구·숫자·일정·스택은 개발 기준이 아닙니다.
2. `references/user_photos/`: 사용자가 제공한 원작 카드/설명서 사진 9장. 비공개 규칙 확인 자료입니다. public/assets/CDN/공개 저장소에 올리지 않습니다.
3. `visuals/`: 동봉 HTML의 화면을 렌더링한 신규 UI 시안. 실제 제품 스크린샷이나 서버 연결 결과가 아닙니다.
4. `assets/`: 실제 제작 시 필요한 이미지 규격·디자인 토큰·생성 프롬프트입니다. 완성 카드 일러스트 전체 세트가 들어 있는 것은 아닙니다.

## MVP 아트 제작 목록
홈 배경 1장(1920×1080), 테이블 배경 1장(1920×1080), 게임 커버 5장(1200×800), 별길 경로 일러스트 5장(768×1024), 공통 카드 뒷면 1장(768×1024), 지원 문양 1장(768×1024), 기호5종(SVG), 좌석 아바타8종(256×256). 숫자2~10·제목·설명은 AI 이미지에 넣지 말고 UI가 렌더링합니다. 신규 일러스트가 없어도 CSS 카드로 첫 규칙을 개발할 수 있습니다.

## 공통 생성 원칙
독자적인 하늘 관측/추상 자연 테마, 이미지 안 글자·숫자·로고 없음, 동일 광원·팔레트, 카드 가장자리 안전 여백, 상하 숫자 오버레이 영역 확보, 원작 사진/카드/캐릭터/레이아웃을 재현하라는 지시 금지. 예시 프롬프트는 `assets/IMAGE_PROMPTS.md`를 사용합니다.

## 검수
원작과 구별되는 테마/도상인지, 작은 크기에서도 색/기호가 읽히는지, 5색이 구분되는지, 문자 비슷한 흔적이 없는지, 모바일 카드 상단 숫자와 겹치지 않는지 확인합니다. 투명 배경이 필요한 항목과 배경이 포함된 일러스트를 구분합니다. 대형 PNG를 그대로 전달하지 말고 리사이즈/WebP·AVIF 변환과 lazy loading을 검토합니다.

## 출처 기록
manifest에는 assetId, 파일 경로, 용도, 크기, 생성 도구/일자, 사용한 프롬프트, 수작업 수정, 출처, 공개 사용 검토 상태를 남깁니다. 이 패키지에 폰트 파일은 포함하지 않습니다. 실행 환경의 시스템 글꼴을 사용하며 실제 배포 글꼴 라이선스는 별도 확인합니다.

## 법적 경계
규칙과 창작적 표현은 구분해야 한다는 공식 설명 [S10]을 참고하되, 이 패키지는 특정 완성 게임의 비침해 법률의견이나 상표 사용 허가서가 아닙니다. '무료이므로 무조건 합법', 'AI로 만들었으므로 자동 면책' 같은 문구를 서비스에 쓰지 않습니다. 이름·캐릭터·이미지·설명문·브랜드를 독립 제작하고, 최종 공개물은 별도로 검토합니다. 향후 게임의 조합/콘텐츠 데이터가 원작과 실질적으로 유사한지에 대한 검토를 생략한 채 출시하지 않습니다.

## 저장소 배포 경계
공개 빌드는 `apps/web/public/`의 승인된 런타임 에셋만 포함합니다. `references/`, 비공개 snapshot, 운영 키, 원작 사진이 포함되지 않는지 CI에서 검사합니다. 동봉 ZIP은 개인 개발 작업용 자료이며 그대로 공개 홈페이지에 업로드하는 파일이 아닙니다.
