# 07. 검수·운영·보안

## 테스트 층
| 층 | 목적 | 실제 실행 여부 |
|---|---|---|
| 규칙 단위 | 점수·합법 행동·불변식·원본 불변 | 동봉 코드 실행 결과 참조 |
| 프로토타입 | 화면 이동·모바일 overflow·콘솔 오류 | 동봉 검증 보고 참조 |
| 계약 통합 | JSON 검증·버전·인증·중복 처리 | 서버 구현 후 필요 |
| DB 통합 | 트랜잭션/권한/중복키/복구 | 미실행 |
| 브라우저 대전 | 실제 2계정, 2네트워크 | 미실행 |
| 부하/보안 | 다중 방·토큰·침투·장애 | 미실행 |

## 첫 게임 필수 테스트 시나리오
60장 생성, 8장 배분, 최초 44장 / 감소 배치 거절 / 지원 카드 순서 / 버린 카드 즉시 회수 금지 / 다른 색 버림 회수 / 빈 더미 / 최종 덱 드로우 즉시 종료 / 비어있는 경로0 / 음수 배수 / 8장 지원 포함 / 보너스 비배수 / 동점 / 종료 후 행동 거절 / phase별 손패 장수 / 60장 보존 / 원본 state 불변 / 상대 손패·덱 유출 없음.

## 반드시 추가할 통합 회귀 테스트
- 동일 commandId 재전송: 1회만 처리. 동일 ID에 다른 payload: 거절.
- 서로 다른 명령이 같은 expectedVersion으로 도착: 정확히 하나만 커밋.
- 타 테이블의 sessionId/cardId 위조: 허용되지 않음.
- DB 장애: 승인 전 상태 변경/손패 유출/점수 확정 없음.
- DB 커밋 직후 프로세스 종료: 재접속 후 명령 결과를 찾아 중복 재적용하지 않음.
- PLACE 승인 후 종료: DRAW 단계·7장 손패·justDiscardedId 복원.
- ACK 유실: 동일 ID 재시도 시 원래 결과. state stream version과 조화.
- JWT 만료/위조/다른 issuer/audience, 초대 만료/재사용, 계정 2탭 동시 연결.
- 공개 로그·오류·analytics·관리 화면이 상대 손패나 비밀 덱을 노출하지 않음.
- 브라우저 새로고침과 서버 재시작을 따로 시험.

## 브라우저 검수 제안
PC Chromium/Firefox/WebKit 계열과 실제 iOS Safari/Android Chrome을 검수합니다. 자동화 WebKit만으로 실제 iPhone 검수가 끝났다고 표시하지 않습니다. 1440×1000, 1280×800, 390×844, 360×800 화면과 키보드·터치·확대·모션 줄이기를 확인합니다.

## 운영 체크리스트
TLS/WSS, Origin allowlist, 제한된 CORS, 요청 payload 최대 8KB(첫 카드 게임 기준), 명령 사용자당 초당10회 burst20의 제안 제한, 인증/초대 실패 rate limit, 닉네임·채팅 길이 제한과 텍스트 escape, CSP, 비밀 키 서버 전용, 관리자 최소 권한, npm 의존성 점검, 비공개 DB 스키마 노출 차단을 확인합니다. 후속 타일 게임에서 payload 한도를 바꾸면 별도 부하 검증합니다.

## 장애 처리
DB 접속 불가: 새 명령 일시 중지, 저장 실패 안내, 메모리 상태 임의 진행 금지.
게임 서버 재시작: 신규 게임 일시 차단 → DB snapshot 복원 → userId로 좌석 복구 → latest View 송신.
클라이언트 단절: 연결 안내·입력 중지·유예, 복귀 후 상태 조회. 화면 애니메이션을 근거로 이전 명령 재생 금지.
배포: 진행 중 게임을 drain하거나 호환 버전으로 유지. schemaVersion이 달라 읽을 수 없으면 안전하게 복구 중단/무효 처리하고 손패 유실 승패를 만들지 않습니다.

## 백업/복원
운영 전 별도 테스트 DB에 백업을 복원하고 종료 게임 결과와 진행 중 DRAW 상태가 복원되는지 확인합니다. 현재 상태 영속화와 서비스 공급자 백업은 다른 문제입니다. 공급자 무료 플랜의 백업/휴면 조건을 확인하지 않고 가용성을 약속하지 않습니다.

## 공개 출시 게이트
실제 친구 2명, 서로 다른 브라우저/네트워크로 최소 10판을 끝까지 진행하고 모든 점수 일치. 새로고침/단절/서버 재시작 복구 성공. 스냅샷 권한 테스트와 비밀 정보 패킷 검사 통과. 카드 에셋/글꼴/소리의 사용 권한과 공개 개인정보 안내 확인. 심각한 미해결 결함이 있으면 공개를 미룹니다. 10판은 제안 검수 기준이며 수행 실적이 아닙니다.
