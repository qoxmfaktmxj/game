# 05. 첫 게임 상세 명세 — 별길 탐험
상태: 구현 기준안 · gameKey: `star-trails` · rulesVersion: `1.0.0` · contentVersion: `1.0.0`
원천: 사용자가 제공한 기본 규칙 사진. 아래 문장은 작동 규칙을 새로 정리한 것입니다. 목표 확장은 제외합니다.

## 콘셉트
두 플레이어가 다섯 하늘 길에 관측 기록을 쌓습니다. aurora(원), ember(삼각형), tide(마름모), moss(사각형), dusk(별)는 독자적인 화면 테마용 식별자입니다. 게임 중 숫자와 기호는 텍스트/벡터 UI로 렌더링합니다. 이름은 가칭이며 상표 검토를 완료하지 않았습니다.

## 구성과 준비
각 색에 숫자 2~10 카드가 1장씩, 지원 카드가 3장씩 있습니다. 총 5×(9+3)=60장입니다. 지원 카드는 숫자 0과 구분되는 kind입니다. 서버는 60장의 고유 ID를 생성하고 안전하게 섞은 뒤 번갈아 8장씩 나누어줍니다. 시작 덱은 44장입니다. 첫 차례는 서버 난수로 정합니다. 나이 수집/나이 비교는 사용하지 않는 플랫폼 변형입니다.

## 상태
phase는 PLACE / DRAW / FINISHED입니다. activePlayerIndex, hands, 2×5 경로, 5개 버림 배열, 비공개 deck, justDiscardedId, version을 보관합니다. 카드의 모든 위치를 합하면 항상 원래 60장의 정확한 집합이어야 합니다.

## PLACE 단계
내 손패에서 정확히 한 장을 고릅니다. 내 경로에 놓거나 버립니다. 다른 플레이어 경로에 놓을 수 없습니다.

배치: 같은 색 경로만 가능합니다. 숫자 카드는 그 경로의 마지막 숫자보다 반드시 커야 합니다. 중간 숫자를 건너뛰는 것은 가능하지만 이후 낮은 숫자로 돌아갈 수 없습니다. 지원 카드는 숫자 카드가 한 장도 없는 경로에만 놓습니다. 지원 카드는 최대 3장이고, 이미 숫자를 놓은 경로에는 나중에 끼워 넣지 못합니다.

버리기: 해당 색 버림 더미 맨 위로 옮깁니다. justDiscardedId를 저장합니다. 경로에서 거절될 카드도 손패에서 버리는 것은 가능합니다.

배치/버리기를 승인하면 손패는 7장, phase는 DRAW가 됩니다. 이 상태를 즉시 저장합니다. 아직 상대 차례가 아닙니다.

## DRAW 단계
뒷면 덱에서 한 장 또는 임의 색 버림 더미의 맨 위 한 장을 가져옵니다. 빈 버림 더미는 선택할 수 없습니다. 방금 내가 버린 카드는 같은 차례에 다시 가져올 수 없습니다. 이는 카드 ID로 검사합니다. 그 아래 카드를 건너뛰어 가져올 수도 없습니다.

뽑기를 승인하면 손패가 8장입니다. 덱의 마지막 카드를 뽑았다면 즉시 FINISHED, 점수 계산입니다. 마지막 카드를 플레이할 추가 차례는 없습니다. 그렇지 않으면 상대 차례 PLACE로 전환하고 justDiscardedId를 비웁니다. 버림 더미에서 뽑았으면 덱 장수는 줄지 않습니다.

## 점수
비어 있는 경로는 0점입니다. 한 장이라도 있으면:

`경로 점수 = (숫자 합계 - 20) × (지원 카드 수 + 1) + (전체 카드 수 ≥ 8 ? 20 : 0)`

지원 카드는 8장 보너스의 장수에 포함합니다. 보너스 20점은 배수 적용 후 더하며 배수로 늘리지 않습니다. 음수에도 배수가 적용됩니다. 각 플레이어는 다섯 경로를 합산합니다. 손패는 점수에 넣지 않습니다.

| 경로 | 계산 | 점수 |
|---|---|---:|
| 비어 있음 | 시작하지 않은 경로 | 0 |
| 지원 1장만 | (0-20)×2 | -40 |
| 5,8,10 | 23-20 | 3 |
| 지원 1장 + 3,5,7 | (15-20)×2 | -10 |
| 지원 2장 + 2,3,5,7,8,10 | (35-20)×3+20 | 65 |
| 지원 3장 + 2~10 전체 | (54-20)×4+20 | 156 |

최고 점수가 같으면 공동 승리입니다. 원작 설명서의 나이 기반 동점 처리 대신 채택한 플랫폼 정책입니다. 첫 버전은 단판이며 3판 합산은 후속 규칙 옵션입니다.

## 예외와 판단
- phase=PLACE이고 내 차례가 아니면 어떤 플레이/버리기도 거절합니다.
- 숫자 7 뒤에 6, 지원 카드 뒤 숫자 2 뒤 지원 카드 등은 거절합니다.
- DRAW 때 플레이/버리기, PLACE 때 뽑기는 거절합니다.
- 종료 후에는 새 명령을 받지 않습니다. 재경기는 새 세션입니다.
- 무한히 버림 더미를 주고받으면 덱이 줄지 않을 수 있습니다. 규칙에 없는 강제 덱 소진은 넣지 않습니다. 참가자 합의 중단 또는 운영 이탈 정책으로 처리합니다.
- 메인 덱이 비지 않았는데 종료로 바뀌는 경우는 기권/무효 종료를 담당하는 룸 서비스입니다. 자연 종료와 구분합니다.
- 명령 거절은 버전·손패·덱·차례를 바꾸지 않습니다.

## 공개 View
내 손패만 카드 상세를 포함합니다. 상대 손패는 장수만. 각 경로는 공개, 버림 더미는 맨 위와 장수만, 덱은 장수만 공개합니다. 카드 ID 자체가 색/숫자를 암시하지 않게 실제 서버에서 무작위 opaque ID를 만듭니다. 참조 코드의 고정 ID 생성기는 테스트용이며 프로덕션에 사용하지 않습니다.

## 필수 불변식
60개 고유 카드 보존 / 숫자 경로의 엄격 증가 / 지원은 숫자 이전 / phase별 손패 8 또는 7 / 덱 장수 비음수 / 점수는 상태에서만 계산 / 원본 상태 불변 / 상대 비밀 미전송.

## 참조 구현의 범위
`rules-reference/engine.mjs`는 덱 생성·초기화·배치·버리기·뽑기·점수·플레이어 View·불변식 검사를 구현합니다. 서버 인증·메시지 스키마 통합·DB·실제 난수 주입·기권 정책·타임아웃은 구현하지 않습니다. 이를 완성된 네트워크 게임으로 취급하면 안 됩니다.
