# 하늘 깡총 확정과 저장소 반영

Status: resolved
Label: ready-for-agent

2026-10-26: 사용자 확정안은 최신50면이며 멍이10은 회색 보더콜리 v5다. 실제 카드·모아보기·대기실에 연결하고 이전 밝은 동물 테이블/카드 드래그 작업과 함께 검증·커밋·푸시한다. 추가 요청으로 홈 탭 제목은 링구링구, 테이블은 링구링구 - 게임이름이다. 원격의 서버 재시작 복구/부하 시험 수정은 보존한다. 원격 배포 실행은 사용자 오픈클로에서 수행한다.

실험 이미지와 검수 스크린샷은 로컬에 보존하고, 서비스에 필요한 최종 이미지 및 변경 코드·생성 근거를 버전 관리한다. 개인 원본사진·비밀정보는 포함하지 않는다.

## 완료 조건

최종50개 경로/고유 이미지 연결, 회색 보더콜리 확인, 홈·테이블 제목 동기화, 타입·자산·규칙·빌드 및 필요한 브라우저 점검, 원격 최신변경 통합, 정상 push와 원격커밋 확인.
