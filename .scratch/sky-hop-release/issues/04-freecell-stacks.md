# 프리셀 형태의 공개 카드 쌓임

Status: resolved
Label: ready-for-agent
Owner: root

## 요청과 완료 조건

2026-10-26 사용자 예시처럼 상대·내 길과 버림 더미를 먼저 놓은 카드부터 아래로 겹쳐 보여준다. 이전 카드 모두의 숫자/×2를 읽을 수 있고 마지막 카드는 전체 면을 보인다. 버림 더미를 누르면 전체를 순서대로 열람하고, 가져오기는 별도 버튼으로 맨 마지막 카드만 처리한다. 방금 버린 더미에서 같은 차례에 다시 가져올 수 없는 기존 제한은 유지한다.

## 구현

- 실제 PlayingCard를 사용하는 공통 CardStack으로 최근 4장 제한을 제거했다.
- PlayerView의 버림 더미에 오래된 카드부터 최신 카드까지 복사한 cards를 추가했다. top/count는 유지한다.
- 전체 공개에 대한 사용자 결정과 원본 명세 차이는 docs/star-trails-display.md에 기록했다. 원본 패키지는 보존했다.
- 데스크톱과 모바일에서 카드 높이와 겹침 간격에 맞춰 더미 높이가 늘어난다. 모션 감소 처리는 유지한다.

## 검증

- npm run check 성공: 전체 워크스페이스 타입 검사, 테스트 167개 통과·선택적 PostgreSQL 통합 1개 미실행, 게임 서버 및 Next.js 운영 빌드 통과.
- 순수 규칙 테스트는 42개 통과하며 100판 자동 진행, 두 플레이어의 버림 전체 공개 순서, 복사 격리·비공개 정보 보호·맨 위 카드만 가져오기 검사를 포함한다.
- 실제 컴포넌트를 SSR한 로컬 검수 예시 43면: ×2/3/4/6/9, 최대 12장, 비순차 버림 3/9/2/6의 순서와 마지막 전체 면 확인. 데스크톱 및 360px CUA 화면에서 숫자 띠·전체 마지막 카드가 보이고 모바일 가로 넘침 없음.
- 실제 로컬 게임 CUA: 지원 ×2 위에 숫자 3 놓기, 버림 랑이 3 열람 후 명시적 가져오기, 물개 2를 기존 물개 4 위로 드래그해 버리기, 상세창에서 4/2 전체 확인. 열람 중 손패 7장 불변과 방금 버린 더미의 가져오기 비활성 확인.
- 실제 게임 새로고침 후 물개 버림 순서 4/2, 손패 7장, DRAW 단계와 재획득 제한 복구 확인.
- 관련 E2E 두 파일의 가져오기/상세 보기 선택자와 손패 불변 검사를 갱신했다. --list로 6개 테스트 로드만 확인했으며 이번 변경 후 E2E 브라우저 전체 실행은 하지 않았다.
- 로컬 검수 화면·스크린샷은 .scratch 및 ignored public/art/studies에만 보존한다. 외부 DB·원격 배포와 실물 모바일 터치는 이번 범위에서 실행하지 않았다.
