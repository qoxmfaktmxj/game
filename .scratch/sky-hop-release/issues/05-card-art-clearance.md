Status: resolved

Owner: root

## 요청과 완료 조건

2026-10-26: 숫자가 동물 그림을 가리지 않도록 손패·공개 길·버림 더미·상세창·갤러리·드래그 카드에서 상단 숫자, 가운데 그림, 하단 동물 이름 영역을 분리한다. 작은 카드의 그림이 과도하게 축소되지 않도록 카드 높이도 조정한다. 프리셀 겹침은 이전 숫자만, 마지막 전체 면을 보인다.

추가 요청: 버튼은 버리기/놓기. 1/2 대신 놓기·버리기/가져오기로 단계를 설명한다. 설정의 기권과 로그아웃은 좌우로 떨어뜨린다. 앱의 애니메이션 줄이기 옵션과 개인 설정을 제거하고 기본 모션은 게임 조작을 지연하지 않게 유지한다.

## 검증

독립 소스 검토에서 모바일 버림 카드의 부족한 그림 공간과 갤러리·드래그 오버라이드 충돌을 확인했다. 3행 Grid와 relative 그림 창으로 해결하고, 기존 이미지 하단 padding 및 숫자 absolute 배치를 제거했다. 공개 카드 높이를 늘려 그림 공간을 확보하고 프리셀 겹침 간격을 숫자 영역 높이와 연결했다.

- npm run check: 전체 타입 검사, 167개 테스트 통과·선택적 PostgreSQL 1개 미실행, 게임 서버와 웹 운영 빌드 성공.
- 실제 CardStack/PlayingCard 43면 SSR 검수 예시를 재생성했다. 데스크톱과 360px CUA에서 상단 숫자/그림/하단 이름 경계 겹침 0건, 이전 숫자와 마지막 그림 확인. 360px에서 가로 넘침 없음, 작은 버림 카드의 실제 그림 영역 높이 최소 약42px.
- 실제 /cards 50면을 데스크톱과 360px에서 검사해 정보와 그림 영역 겹침 0건, 360px 가로 넘침 없음. 이미지 원본은 변경하지 않았다.
- 실제 진행 중인 게임의 손패 8장과 길 상세 카드 2장에서 영역 겹침 0건 확인. 버리기/놓기 버튼, 놓기·버리기 단계 문구 확인. 선택과 상세 열람만 했으며 사용자 판의 카드를 제출하지 않았다.
- 실제 설정창에서 토글 없음, 기권 왼쪽·로그아웃 오른쪽, 두 버튼 44px 높이 확인. OS 모션 감소 지원은 유지하되 앱의 개인 설정과 저장·전달 코드를 제거했다.
- 기존 기본 모션은 서버 승인 후 transform/opacity로 재생되고 완료를 게임 명령 전제조건으로 삼지 않는다. 이번 작업은 성능 벤치마크를 수행했다는 의미가 아니다.
- Impeccable layout 감지 전/후 지적 0건. E2E 소스 선택자·OS 모션 테스트를 갱신했으나 전체 브라우저 E2E, 실물 터치 기기, 원격 배포는 이번 작업에서 실행하지 않았다.
