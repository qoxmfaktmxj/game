# 카드 동물 아이콘 하단 이동

Status: resolved
Label: ready-for-agent
Owner: root

## 요청과 완료 조건

숫자/×2 아래의 동물 아이콘이 그림을 가리므로 카드 하단 이름 옆으로 이동한다. 손패·내려놓은 카드·버림·갤러리 공통 적용. 숫자와 배수 표시는 유지하고 작은 모바일 카드에서 이름/오른쪽 표찰과 겹치지 않게 확인한다.

## 검증

- 숫자/×2 아래 아이콘을 제거하고 흰 하단 표찰의 이름 왼쪽에 배치했다. 기본12px, 갤러리18px(모바일16px), 작은 보드9px.
- 웹 타입 검사·Prettier·diff 공백 검사 통과.
- 실제 보드 카드10개와 갤러리50개에서 상단 아이콘0/하단 아이콘 카드 수와 일치 확인.
- 360px 화면 가로 넘침 없음. 작은 버림 카드45.125px 폭에서 아이콘9px, 이름과 오른쪽 숫자 간격 약5.8px로 겹침 없음.
- card-icon-detail.jpg, card-icon-mobile.jpg에 실제 화면 보존. 규칙과 카드 숫자는 변경하지 않았다.
