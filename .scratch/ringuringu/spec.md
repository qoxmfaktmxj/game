# 링구링구 브랜드·모션과 연결 흐름 개선

Status: resolved
Label: ready-for-agent

## 확정 범위

서비스와 첫 게임의 표시 이름은 링구링구로 통일한다. 기존 별길 탐험의 확정 규칙, 내부 gameKey와 원본 자료를 보존한다. 시각 방향은 cream/forest와 서체를 발전시키고, 고리 로고·카드 테이블 모션을 적용한다. OS·앱의 움직임 줄이기와 직접 일시정지를 지원한다.

초대·재접속·테이블 탈퇴 UI를 정리하고 타입 검사, 실제 두 브라우저 플레이, 모바일 화면으로 검증한다.

## 사용자 결정

2026-10-23: 처음 요청한 Supabase·DB·실제 배포는 이후로 미룬다. Vercel 배포를 기준으로 준비하되 외부 계정 연결이나 리소스 생성은 지금 진행하지 않는다. 기존 인증 어댑터는 미연결 상태로 두고 인증·DB의 최종 방식은 배포 재개 시 확정한다.

## 검증

전체 타입 검사·프로덕션 빌드, 규칙 41개, 서버 14개(기존 전체 13개 + 새 운영 회귀 포함 4개 재검증), 빌드 산출물 네트워크 복구 1개, 최종 브라우저 E2E 5개가 통과했다. 독립 소스 리뷰에서 발견한 장애·탈퇴 경계 2건을 수정하고 회귀를 추가했다. 최신 화면 10개 기반 독립 시각 리뷰는 ship 판정이다. 상세 실행 결과와 미검증 범위는 `docs/verification.md`에 기록했다.
