# 나머지 게임 개별 카드 아트

Status: resolved
Label: ready-for-agent

사용자 요청: 별길 탐험과 같은 느낌으로 나머지 게임 카드 이미지를 하나씩 모두 생성하고 적용한다.

## 완료 조건

- 내장 imagegen 개별 호출로 231종 생성, 원본과 프롬프트 기록.
- 빛의 공방 100종, 밤의 의회 36종, 황혼의 신호 42종, 넘버가든 53종.
- 동일 종류 복사본은 같은 그림 사용. 숫자·비용·효과는 기존 데이터와 HTML 유지.
- 공개 View 경계 유지, 갤러리·실제 화면·모바일 검수, 타입 검사와 빌드.

## 검증

231종을 내장 imagegen으로 각각 생성하고 게임 및 갤러리에 적용했다. 원본 231개와 최종 프롬프트를 `docs/art/`에 기록했다. 기존 별길 탐험 50종 포함 총 281종이다.

전체 파일·PNG 해상도·고유 해시 검사, TypeScript 검사, 서버·웹 빌드 통과. 규칙 107개와 서버 59개 시험 통과(실제 PostgreSQL 1개 건너뜀). 빌드된 서버 SDK 시험 4개, 전체 브라우저 시나리오 16개 통과. 최종 화면은 `artifacts/all-game-art-final/`에 남겼다. 실제 운영 배포는 별도다.

사용자가 작업 완료 후 `qoxmfaktmxj/game` 저장소로 푸시하도록 명시했다. 개인 사진·실제 환경 파일·로컬 저장 데이터·검증 산출물은 커밋에서 제외한다.
