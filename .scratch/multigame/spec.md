# 다섯 게임과 Ring Club 디자인

Status: resolved
Label: ready-for-agent

사용자는 최신 디자인 레퍼런스를 넓게 조사한 뒤 화면을 개선하고, 나머지 네 게임도 모두 구현하도록 요청했다. 추가 게임은 공식 기본판 규칙을 따르며 이름과 그림은 자체 제작한다. 후속 요청으로 다섯 게임의 중간 난이도 연습 봇, 별길 탐험 이름 분리, 유기적 카드 문양, 짧은 홈 문구를 추가한다. 배포 기준은 자체 리눅스 Docker Compose·PostgreSQL·game.minseok91.cloud·약 8GB RAM, 100명 동시접속 목표이며 원격 실행은 사용자의 오픈클로에서 이어간다.

## 완료 조건

- 날짜와 관찰 근거가 있는 디자인 레퍼런스 문서와 일관된 새 화면.
- 빛의 공방·밤의 의회·황혼의 신호·넘버가든의 전체 기본 규칙과 검증 가능한 데이터.
- 같은 테이블에서 게임 선택·가변 인원·준비·시작·진행·결과·재경기.
- 게임별 비공개 정보, 서버 권한, 저장·재연결, 중복 명령 보존.
- 의미 있는 규칙 테스트, 네트워크 통합 검증, 데스크톱·모바일 검수.
- 원작과 다른 규칙이나 미확인 콘텐츠가 있으면 완료로 표시하지 않는다.

## 작업

- 루트: 넘버가든 엔진, 화면 통합, 전체 검증.
- multigame_arch_v3: 공통 계약·저장·게임 서버.
- rules_sources_v3: 공식 규칙 및 데이터 근거, 황혼의 신호.
- design_reference_v3: 디자인 조사·홈·스타일·자체 아트.

## 검증

2026-10-24 기준 전체 타입 검사 통과, 코어 107개 테스트 통과, 서버 60개 중 59개 통과·실제 PostgreSQL 시험 1개 건너뜀. 서버 빌드와 빌드된 서버의 실제 SDK 복구·자연 종료 시험 4개가 통과했다. 최신 보안 제한에서 100개 연결·50개 테이블·60.08초·4,557명령을 실행해 오류와 예상치 못한 끊김이 없었고 p95는 39.06ms였다.

별길 탐험 일러스트 50종을 내장 imagegen으로 개별 생성하고 실제 60장 덱·손패·길 상세와 `/cards` 갤러리에 적용했다. 50개 고유 파일·해상도·브라우저 이미지 로딩이 정상이며, 최종 전체 타입 검사와 웹 production build, Playwright 12개 시나리오가 모두 통과했다. 이미지 원본·프롬프트는 `docs/card-art.md`, 상세 검증은 `docs/verification-multigame.md`, 이전 첫 게임 검증은 `docs/verification.md`에 기록한다.

로컬 구현과 자체 서버 배포 준비 범위는 완료했다. 실제 Docker·PostgreSQL·공개 도메인·운영 부하와 백업·복원은 실행하지 않았으며 사용자의 오픈클로에서 `docs/openclaw-handoff.md`를 따라 이어서 확인해야 한다. 공개 서비스가 배포되었다는 의미가 아니다.
