## 범위

원본 패키지의 제안 시간을 실제 운영 정책으로 확정한 뒤, 방장 이탈 60초 후 위임·단절 180초 후 종료 선택·빈 Room 15분 보관·전원 오프라인 24시간 종료·기록 삭제를 구현한다. 현재 단절 시 서버 명령 정지와 복귀는 검증되어 있다.

추가 화면은 닉네임 변경, 결과에서 대기실 복귀, 공개 행동 기록이다. 다음 게임은 별도 규칙과 콘텐츠 확정 뒤 시작한다.

2026-10-23: 대기실·결과 설정의 LEAVE UI를 구현했다. 서버 ACK 뒤 목록으로 돌아가고 남은 멤버에게 호스트를 넘긴다. 목록 재조회 실패가 탈퇴 완료 화면 이동을 막지 않도록 처리했다. 관련 UI 회귀는 링구링구 개선 검증에 포함한다.

## 완료 조건

시간을 주입한 수명 테스트, 두 클라이언트에서 종료 이유와 준비 초기화·좌석·재접속 일치, 기존 첫 게임 회귀 검사 통과.
