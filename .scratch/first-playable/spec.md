# 첫 번째 실제 플레이 버전

Status: resolved
Label: ready-for-agent

친구 두 명이 테이블에 입장해 준비하고, 별길 탐험을 끝까지 진행한 뒤 같은 테이블에서 재경기한다. 규칙은 원본 패키지의 확정 명세를 따른다.

## 완료 조건

- 순수 TypeScript 규칙과 플레이어 정보 경계 검증.
- 서버 권위 명령 처리, 중복 방지, 저장 실패 원복, 복구 검증.
- 홈·목록·대기실·게임·결과·규칙 안내의 실제 연결.
- 데스크톱 및 390/360px 모바일의 조작·넘침 검수.
- 로컬 검증과 외부 Supabase/PostgreSQL 검증 상태를 명확히 기록.

## 범위

다른 네 게임, 클라우드 배포, 최종 브랜딩·도메인·OAuth 공급자 선택은 후속 작업이다. 이번 작업에서 서비스 계약이나 유료 리소스를 생성하지 않는다.
